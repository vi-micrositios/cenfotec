Ejercicio 1: Cálculo de recursos necesarios para una misión

Estructura de control: secuencial.

Tabla de variables

Nombre Tipo de dato Descripción Clasificación Valor inicial / restricciones
CONSUMO_COMBUSTIBLE_DIA int Unidades de combustible que se consumen por día de viaje. Constante 8
RESERVA_COMBUSTIBLE int Combustible adicional obligatorio para emergencias. Constante 10
CONSUMO_OXIGENO_DIA int Oxígeno que consume un tripulante por día. Constante 2
OXIGENO_EMERGENCIA int Oxígeno adicional de emergencia. Constante 5
CONSUMO_ENERGIA_DIA int Energía que consume la nave por día. Constante 5

tripulantes int Cantidad de tripulantes. Entrada Entero positivo
dias_viaje int Días estimados para llegar al destino. Entrada Entero positivo
combustible_ida int Combustible necesario para llegar. Salida Calculado
combustible_regreso int Combustible necesario para regresar. Salida Calculado
combustible_total int Combustible de ida, regreso y reserva. Salida Calculado
oxigeno_requerido int Oxígeno para ida, regreso y emergencia. Salida Calculado
energia_requerida int Energía para ida, regreso y exploración. Salida Calculado
provisiones_requeridas int Provisiones para ida, regreso y adicionales. Salida Calculado

Diagrama de flujo

Código — ejercicio1_recursos.py

# ============================================================
# Archivo: ejercicio1_recursos.py
# Curso: SOFT-01 Principios de Programación 1 - Sección SCV6
# Integrantes: Solución de referencia (docente)
# Fecha: 21/10/2026        Versión: 1.0
# Descripción: Calcula los recursos necesarios (combustible, oxígeno,
#              energía y provisiones) para una misión de ida y regreso.
# ============================================================

# ---------- Constantes ----------
# Consumos por día y márgenes definidos por la agencia.
CONSUMO_COMBUSTIBLE_DIA = 8
RESERVA_COMBUSTIBLE = 10
CONSUMO_OXIGENO_DIA = 2         # por tripulante
OXIGENO_EMERGENCIA = 5
CONSUMO_ENERGIA_DIA = 5
ENERGIA_EXPLORACION = 10
CONSUMO_PROVISIONES_DIA = 1     # por tripulante
PROVISIONES_ADICIONALES = 3
TRAYECTOS = 2                   # el viaje incluye ida y regreso

# ---------- Entrada de datos ----------
nombre_mision = input("Nombre de la misión: ")
tripulantes = int(input("Cantidad de tripulantes: "))
dias_viaje = int(input("Días estimados para llegar al destino: "))

# ---------- Procesamiento ----------
# El regreso dura lo mismo que la ida, por eso ambos consumen igual.
combustible_ida = dias_viaje * CONSUMO_COMBUSTIBLE_DIA
combustible_regreso = dias_viaje * CONSUMO_COMBUSTIBLE_DIA
combustible_total = combustible_ida + combustible_regreso + RESERVA_COMBUSTIBLE

# Oxígeno, energía y provisiones se calculan para ida y regreso
# (TRAYECTOS) y se les suma su margen adicional.
oxigeno_requerido = dias_viaje * CONSUMO_OXIGENO_DIA * TRAYECTOS * tripulantes + OXIGENO_EMERGENCIA
energia_requerida = dias_viaje * CONSUMO_ENERGIA_DIA * TRAYECTOS + ENERGIA_EXPLORACION
provisiones_requeridas = dias_viaje * tripulantes * CONSUMO_PROVISIONES_DIA * TRAYECTOS + PROVISIONES_ADICIONALES

# ---------- Salida de resultados ----------
print()
print("Misión:", nombre_mision)
print("Tripulantes:", tripulantes)
print("Duración estimada hasta el destino:", dias_viaje, "días")
print("Combustible para llegar:", combustible_ida, "unidades")
print("Combustible para regresar:", combustible_regreso, "unidades")
print("Reserva de combustible:", RESERVA_COMBUSTIBLE, "unidades")
print("Combustible total requerido:", combustible_total, "unidades")
print("Oxígeno requerido:", oxigeno_requerido, "unidades")
print("Energía requerida:", energia_requerida, "unidades")
print("Provisiones requeridas:", provisiones_requeridas, "unidades")
Nota: El factor 2 de las fórmulas (ida y regreso) también es un número mágico, por eso se declara como la constante TRAYECTOS.

Ejercicio 2: Verificación de combustible

Estructura de control: condicional simple.

Tabla de variables

Diagrama de flujo

Código — ejercicio2_combustible.py

# ============================================================
# Archivo: ejercicio2_combustible.py
# Curso: SOFT-01 Principios de Programación 1 - Sección SCV6
# Integrantes: Solución de referencia (docente)
# Fecha: 21/10/2026        Versión: 1.0
# Descripción: Calcula el combustible total requerido y el margen
#              adicional, y advierte si ese margen es bajo.
# ============================================================

# ---------- Constantes ----------
RESERVA_COMBUSTIBLE = 10
MARGEN_MINIMO = 10    # por debajo de este margen se muestra la advertencia

# ---------- Entrada de datos ----------
combustible_disponible = int(input("Combustible disponible: "))
combustible_ida = int(input("Combustible requerido para el viaje de ida: "))
combustible_regreso = int(input("Combustible requerido para el viaje de regreso: "))

# ---------- Procesamiento ----------
# El total incluye el regreso y la reserva: llegar no es suficiente.
combustible_total = combustible_ida + combustible_regreso + RESERVA_COMBUSTIBLE
combustible_adicional = combustible_disponible - combustible_total

# ---------- Salida de resultados ----------
print()
print("Combustible disponible:", combustible_disponible, "unidades")
print("Combustible requerido para llegar:", combustible_ida, "unidades")
print("Combustible requerido para regresar:", combustible_regreso, "unidades")
print("Reserva de emergencia:", RESERVA_COMBUSTIBLE, "unidades")
print("Combustible total requerido:", combustible_total, "unidades")
print("Combustible adicional:", combustible_adicional, "unidades")

# ---------- Decisión (condicional simple) ----------
# Solo se advierte cuando el margen es estrictamente menor que el mínimo.
if combustible_adicional < MARGEN_MINIMO:
    print("Advertencia: el margen adicional de combustible es bajo.")
Nota: La rúbrica pide seis salidas obligatorias, pero el enunciado lista cinco. La sexta es el combustible adicional, que se muestra para que se entienda la advertencia. La condición usa <: con un margen de exactamente 10 no se advierte (CP-06).

Ejercicio 3: Verificación del soporte para la tripulación

Estructura de control: condicional doble con condición compuesta (and).

Diagrama de flujo

Código — ejercicio3_soporte_tripulacion.py

# ============================================================
# Archivo: ejercicio3_soporte_tripulacion.py
# Curso: SOFT-01 Principios de Programación 1 - Sección SCV6
# Integrantes: Solución de referencia (docente)
# Fecha: 21/10/2026        Versión: 1.0
# Descripción: Verifica si el oxígeno y las provisiones disponibles
#              alcanzan para la tripulación.
# ============================================================

# ---------- Entrada de datos ----------
oxigeno_disponible = int(input("Oxígeno disponible: "))
oxigeno_requerido = int(input("Oxígeno requerido: "))
provisiones_disponibles = int(input("Provisiones disponibles: "))
provisiones_requeridas = int(input("Provisiones requeridas: "))

# ---------- Decisión (condicional doble) ----------
# Ambos recursos deben alcanzar; basta que uno falte para rechazar.
print()
if oxigeno_disponible >= oxigeno_requerido and provisiones_disponibles >= provisiones_requeridas:
    print("La nave posee recursos suficientes para la tripulación.")
else:
    print("La nave no posee recursos suficientes para la tripulación.")

Ejercicio 4: Autorización inicial de lanzamiento

Estructura de control: condicional doble sin anidación, con condición compuesta de los cuatro recursos.

Código — ejercicio4_autorizacion.py

# ============================================================
# Archivo: ejercicio4_autorizacion.py
# Curso: SOFT-01 Principios de Programación 1 - Sección SCV6
# Integrantes: Solución de referencia (docente)
# Fecha: 21/10/2026        Versión: 1.0
# Descripción: Autoriza el lanzamiento solo si los cuatro recursos
#              cubren lo requerido, incluido el combustible de regreso.
# ============================================================

# ---------- Constantes ----------
RESERVA_COMBUSTIBLE = 10

# ---------- Entrada de datos ----------
combustible_disponible = int(input("Combustible disponible: "))
combustible_ida = int(input("Combustible requerido para llegar al destino: "))
combustible_regreso = int(input("Combustible requerido para regresar: "))
oxigeno_disponible = int(input("Oxígeno disponible: "))
oxigeno_requerido = int(input("Oxígeno requerido: "))
energia_disponible = int(input("Energía disponible: "))
energia_requerida = int(input("Energía requerida: "))
provisiones_disponibles = int(input("Provisiones disponibles: "))
provisiones_requeridas = int(input("Provisiones requeridas: "))

# ---------- Procesamiento ----------
# El combustible se compara contra el total (ida + regreso + reserva)
# para no autorizar misiones que solo pueden llegar al destino.
combustible_total = combustible_ida + combustible_regreso + RESERVA_COMBUSTIBLE

# ---------- Decisión (condicional doble sin anidación) ----------
print()
if (combustible_disponible >= combustible_total
        and oxigeno_disponible >= oxigeno_requerido
        and energia_disponible >= energia_requerida
        and provisiones_disponibles >= provisiones_requeridas):
    print("Lanzamiento autorizado.")
else:
    print("Lanzamiento no autorizado. La misión debe ser revisada.")
Nota: La condición larga se divide en varias líneas usando paréntesis, que es la forma recomendada por PEP 8 (sin \).
