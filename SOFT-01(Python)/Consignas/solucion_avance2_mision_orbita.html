Ejercicio 5: Selección del destino y autorización de la misión

Estructuras de control: condicional doble (validación de la opción), condicional múltiple (destino y duración) y condicional anidada (autorización).

Diagrama de flujo

Código — ejercicio5_destino.py

# ============================================================
# Archivo: ejercicio5_destino.py
# Curso: SOFT-01 Principios de Programación 1 - Sección SCV6
# Integrantes: Solución de referencia (docente)
# Fecha: 21/10/2026        Versión: 1.0
# Descripción: Determina la duración del viaje según el destino
#              y decide si la misión puede autorizarse.
# ============================================================

# ---------- Constantes ----------
DIAS_LUNA = 3
DIAS_MARTE = 5
DIAS_EUROPA = 7
CONSUMO_COMBUSTIBLE_DIA = 8
RESERVA_COMBUSTIBLE = 10
CONSUMO_OXIGENO_DIA = 2         # por tripulante
OXIGENO_EMERGENCIA = 5
CONSUMO_ENERGIA_DIA = 5
ENERGIA_EXPLORACION = 10
CONSUMO_PROVISIONES_DIA = 1     # por tripulante
PROVISIONES_ADICIONALES = 3
TRAYECTOS = 2                   # ida y regreso

# ---------- Entrada de datos ----------
nombre_mision = input("Nombre de la misión: ")
tripulantes = int(input("Cantidad de tripulantes: "))
print("Destinos: 1. Luna  2. Marte  3. Europa")
opcion_destino = int(input("Opción de destino: "))

# ---------- Validación de la opción (condicional doble) ----------
if opcion_destino >= 1 and opcion_destino <= 3:
    # Condicional múltiple: la opción determina el destino y la duración.
    if opcion_destino == 1:
        destino = "Luna"
        dias_viaje = DIAS_LUNA
    elif opcion_destino == 2:
        destino = "Marte"
        dias_viaje = DIAS_MARTE
    else:
        destino = "Europa"
        dias_viaje = DIAS_EUROPA

    combustible_disponible = int(input("Combustible disponible: "))
    oxigeno_disponible = int(input("Oxígeno disponible: "))
    energia_disponible = int(input("Energía disponible: "))
    provisiones_disponibles = int(input("Provisiones disponibles: "))

    # Mismas fórmulas del Avance 1.
    combustible_ida = dias_viaje * CONSUMO_COMBUSTIBLE_DIA
    combustible_regreso = dias_viaje * CONSUMO_COMBUSTIBLE_DIA
    combustible_total = combustible_ida + combustible_regreso + RESERVA_COMBUSTIBLE
    oxigeno_requerido = dias_viaje * CONSUMO_OXIGENO_DIA * TRAYECTOS * tripulantes + OXIGENO_EMERGENCIA
    energia_requerida = dias_viaje * CONSUMO_ENERGIA_DIA * TRAYECTOS + ENERGIA_EXPLORACION
    provisiones_requeridas = dias_viaje * tripulantes * CONSUMO_PROVISIONES_DIA * TRAYECTOS + PROVISIONES_ADICIONALES

    # ---------- Resumen de la misión ----------
    print()
    print("Misión:", nombre_mision)
    print("Destino:", destino)
    print("Duración del viaje de ida:", dias_viaje, "días")
    print("Tripulantes:", tripulantes)
    print("Combustible disponible:", combustible_disponible, "| requerido:", combustible_total, "unidades")
    print("Oxígeno disponible:", oxigeno_disponible, "| requerido:", oxigeno_requerido, "unidades")
    print("Energía disponible:", energia_disponible, "| requerida:", energia_requerida, "unidades")
    print("Provisiones disponibles:", provisiones_disponibles, "| requeridas:", provisiones_requeridas, "unidades")

    # ---------- Autorización (condicional anidada) ----------
    if (combustible_disponible >= combustible_total
            and oxigeno_disponible >= oxigeno_requerido
            and energia_disponible >= energia_requerida
            and provisiones_disponibles >= provisiones_requeridas):
        print("Lanzamiento autorizado.")
    else:
        print("Lanzamiento no autorizado. La misión debe ser revisada.")
else:
    print("Opción de destino no válida. La misión no puede planificarse.")

Ejercicio 6: Simulación del viaje hacia el destino

Estructuras de control: ciclo while con condición compuesta (días pendientes y variable de control), condicional doble dentro del ciclo y condicionales simples para identificar los recursos insuficientes.

Tabla de variables

Nombre Tipo de dato Descripción Clasificación Valor inicial / restricciones
CONSUMO_COMBUSTIBLE_DIA int Combustible que se consume por día. Constante 8
CONSUMO_OXIGENO_DIA int Oxígeno que consume un tripulante por día. Constante 2
CONSUMO_ENERGIA_DIA int Energía que se consume por día. Constante 5
CONSUMO_PROVISIONES_DIA int Provisiones que consume un tripulante por día. Constante 1
dias_viaje int Cantidad de días del viaje. Entrada Entero positivo
tripulantes int Cantidad de tripulantes. Entrada Entero positivo
combustible / oxigeno / energia / provisiones int Recursos de la nave; se actualizan al final de cada día. Entrada / Salida Entero positivo
consumo_oxigeno / consumo_provisiones int Consumo diario según la cantidad de tripulantes. Intermedia Calculado
dias_transcurridos int Días completados del viaje. Intermedia / Contador 0

Diagrama de flujo

Código — ejercicio6_viaje.py

# ============================================================
# Archivo: ejercicio6_viaje.py
# Curso: SOFT-01 Principios de Programación 1 - Sección SCV6
# Integrantes: Solución de referencia (docente)
# Fecha: 21/10/2026        Versión: 1.0
# Descripción: Simula día a día el viaje hacia el destino y
#              descuenta el consumo diario de los recursos.
# ============================================================

# ---------- Constantes ----------
CONSUMO_COMBUSTIBLE_DIA = 8
CONSUMO_OXIGENO_DIA = 2         # por tripulante
CONSUMO_ENERGIA_DIA = 5
CONSUMO_PROVISIONES_DIA = 1     # por tripulante

# ---------- Entrada de datos ----------
dias_viaje = int(input("Cantidad de días del viaje: "))
tripulantes = int(input("Cantidad de tripulantes: "))
combustible = int(input("Combustible disponible: "))
oxigeno = int(input("Oxígeno disponible: "))
energia = int(input("Energía disponible: "))
provisiones = int(input("Provisiones disponibles: "))

# ---------- Procesamiento ----------
consumo_oxigeno = CONSUMO_OXIGENO_DIA * tripulantes
consumo_provisiones = CONSUMO_PROVISIONES_DIA * tripulantes
dias_transcurridos = 0
puede_continuar = True

print()
# El ciclo termina al completar el viaje o cuando un recurso no alcanza.
while dias_transcurridos < dias_viaje and puede_continuar:
    # Se verifica antes de consumir para no dejar recursos negativos.
    if (combustible >= CONSUMO_COMBUSTIBLE_DIA and oxigeno >= consumo_oxigeno
            and energia >= CONSUMO_ENERGIA_DIA and provisiones >= consumo_provisiones):
        combustible = combustible - CONSUMO_COMBUSTIBLE_DIA
        oxigeno = oxigeno - consumo_oxigeno
        energia = energia - CONSUMO_ENERGIA_DIA
        provisiones = provisiones - consumo_provisiones
        dias_transcurridos = dias_transcurridos + 1
        print("Día", dias_transcurridos, "| Combustible:", combustible, "| Oxígeno:", oxigeno,
              "| Energía:", energia, "| Provisiones:", provisiones)
    else:
        puede_continuar = False

# ---------- Salida de resultados ----------
if puede_continuar:
    print("La nave llegó al destino en", dias_transcurridos, "días.")
    print("Combustible restante:", combustible, "unidades")
    print("Oxígeno restante:", oxigeno, "unidades")
    print("Energía restante:", energia, "unidades")
    print("Provisiones restantes:", provisiones, "unidades")
else:
    print("Viaje interrumpido en el día", str(dias_transcurridos + 1) + ".")
    if combustible < CONSUMO_COMBUSTIBLE_DIA:
        print("Recurso insuficiente: combustible")
    if oxigeno < consumo_oxigeno:
        print("Recurso insuficiente: oxígeno")
    if energia < CONSUMO_ENERGIA_DIA:
        print("Recurso insuficiente: energía")
    if provisiones < consumo_provisiones:
        print("Recurso insuficiente: provisiones")
    print("Días completados:", dias_transcurridos)
Explicación: El ciclo termina por su condición: cuando un recurso no alcanza, puede_continuar pasa a False y el día fallido no se descuenta. Después del ciclo, las condicionales simples (no elif) permiten indicar más de un recurso insuficiente.

Ejercicio 7: Actividades de exploración científica

Diagrama de flujo

Nota: Por espacio, cada bloque «Datos de …» resume la asignación de nombre_actividad, energia_actividad, provisiones_actividad y puntos_actividad con las constantes indicadas. En la entrega de los estudiantes, cada asignación debe escribirse completa. Los círculos numerados son conectores: el flujo continúa en el círculo con el mismo número, junto a la condición del ciclo.

Código — ejercicio7_exploracion.py

# ============================================================
# Archivo: ejercicio7_exploracion.py
# Curso: SOFT-01 Principios de Programación 1 - Sección SCV6
# Integrantes: Solución de referencia (docente)
# Fecha: 21/10/2026        Versión: 1.0
# Descripción: Menú repetitivo de actividades de exploración con
#              contadores de actividades, muestras y puntos.
# ============================================================

# ---------- Constantes ----------
ENERGIA_ANALIZAR = 8
PUNTOS_ANALIZAR = 10
ENERGIA_RECOLECTAR = 12
PROVISIONES_RECOLECTAR = 2
PUNTOS_RECOLECTAR = 20
ENERGIA_OBSERVAR = 5
PUNTOS_OBSERVAR = 8

# ---------- Entrada de datos ----------
energia = int(input("Energía disponible: "))
provisiones = int(input("Provisiones disponibles: "))

# ---------- Valores iniciales ----------
puntos_cientificos = 0
actividades_realizadas = 0
muestras_recolectadas = 0
explorando = True

# ---------- Menú repetitivo ----------
while explorando:
    print()
    print("1. Analizar terreno")
    print("2. Recolectar muestra")
    print("3. Realizar observación")
    print("4. Finalizar exploración")
    opcion = int(input("Seleccione una actividad: "))

    # Valores de la actividad elegida; actividad_valida indica si se debe ejecutar.
    actividad_valida = True
    energia_actividad = 0
    provisiones_actividad = 0
    puntos_actividad = 0
    nombre_actividad = ""
    if opcion == 1:
        nombre_actividad = "Analizar terreno"
        energia_actividad = ENERGIA_ANALIZAR
        puntos_actividad = PUNTOS_ANALIZAR
    elif opcion == 2:
        nombre_actividad = "Recolectar muestra"
        energia_actividad = ENERGIA_RECOLECTAR
        provisiones_actividad = PROVISIONES_RECOLECTAR
        puntos_actividad = PUNTOS_RECOLECTAR
    elif opcion == 3:
        nombre_actividad = "Realizar observación"
        energia_actividad = ENERGIA_OBSERVAR
        puntos_actividad = PUNTOS_OBSERVAR
    elif opcion == 4:
        actividad_valida = False
        explorando = False
        print("Exploración finalizada por la tripulación.")
    else:
        actividad_valida = False
        print("Opción no válida.")

    if actividad_valida:
        # Se verifica antes de descontar: si no alcanza, el estado no cambia.
        if energia >= energia_actividad and provisiones >= provisiones_actividad:
            energia = energia - energia_actividad
            provisiones = provisiones - provisiones_actividad
            actividades_realizadas = actividades_realizadas + 1
            puntos_cientificos = puntos_cientificos + puntos_actividad
            if opcion == 2:
                muestras_recolectadas = muestras_recolectadas + 1
            print("Actividad realizada:", nombre_actividad + ". Puntos obtenidos:", puntos_actividad)
        else:
            print("Recursos insuficientes para realizar la actividad. La exploración finaliza.")
            explorando = False

# ---------- Resumen ----------
print()
print("Actividades realizadas:", actividades_realizadas)
print("Muestras recolectadas:", muestras_recolectadas)
print("Puntos científicos:", puntos_cientificos)
print("Energía restante:", energia, "unidades")
print("Provisiones restantes:", provisiones, "unidades")
Explicación: La condicional múltiple solo asigna los datos de la actividad; la verificación y la actualización se escriben una sola vez, dentro de if actividad_valida. Así no se repite el mismo bloque en tres ramas. La opción 4 no es una actividad: no cuenta ni consume recursos.

Ejercicio 8: Regreso a la Tierra y supervivencia de la tripulación

Estructuras de control: condicional doble (caso A o caso B), ciclo while con variable de control (caso A), condicionales simples para el mínimo y los recursos limitantes (caso B).

Tabla de variables

Nombre Tipo de dato Descripción Clasificación Valor inicial / restricciones
CONSUMO_COMBUSTIBLE_DIA / CONSUMO_ENERGIA_DIA int Combustible y energía que se consumen por día. Constante 8 / 5
CONSUMO_OXIGENO_DIA / CONSUMO_PROVISIONES_DIA int Oxígeno y provisiones que consume un tripulante por día. Constante 2 / 1
tripulantes int Cantidad de tripulantes. Entrada Entero positivo
dias_viaje int Días del viaje de ida (el regreso dura lo mismo). Entrada Entero positivo
combustible / oxigeno / energia / provisiones int Recursos al terminar la exploración; se actualizan durante el regreso. Entrada / Salida Entero positivo

dias_transcurridos int Días completados del regreso. Intermedia / Contador 0

Diagrama de flujo

Nota: Por espacio, el diagrama resume en un solo bloque la resta del consumo diario y la verificación de los recursos insuficientes, que en el ejercicio 6 se muestran desglosadas. En la entrega de los estudiantes, cada asignación y cada decisión deben representarse por separado. Los círculos numerados son conectores que regresan a la condición del ciclo.

Código — ejercicio8_regreso.py

# ============================================================
# Archivo: ejercicio8_regreso.py
# Curso: SOFT-01 Principios de Programación 1 - Sección SCV6
# Integrantes: Solución de referencia (docente)
# Fecha: 21/10/2026        Versión: 1.0
# Descripción: Decide si la nave puede regresar; si puede, simula
#              el regreso y, si no, estima la supervivencia.
# ============================================================

# ---------- Constantes ----------
CONSUMO_COMBUSTIBLE_DIA = 8
CONSUMO_OXIGENO_DIA = 2         # por tripulante
CONSUMO_ENERGIA_DIA = 5
CONSUMO_PROVISIONES_DIA = 1     # por tripulante

# ---------- Entrada de datos ----------
tripulantes = int(input("Cantidad de tripulantes: "))
dias_viaje = int(input("Cantidad de días del viaje de ida: "))
combustible = int(input("Combustible disponible: "))
oxigeno = int(input("Oxígeno disponible: "))
energia = int(input("Energía disponible: "))
provisiones = int(input("Provisiones disponibles: "))

consumo_oxigeno = CONSUMO_OXIGENO_DIA * tripulantes
consumo_provisiones = CONSUMO_PROVISIONES_DIA * tripulantes

print()
# ---------- Decisión: ¿alcanza el combustible para regresar? ----------
# En esta etapa ya no se exige la reserva de emergencia.
if combustible >= dias_viaje * CONSUMO_COMBUSTIBLE_DIA:
    # ----- Caso A: simulación del regreso -----
    dias_transcurridos = 0
    puede_continuar = True
    while dias_transcurridos < dias_viaje and puede_continuar:
        if (combustible >= CONSUMO_COMBUSTIBLE_DIA and oxigeno >= consumo_oxigeno
                and energia >= CONSUMO_ENERGIA_DIA and provisiones >= consumo_provisiones):
            combustible = combustible - CONSUMO_COMBUSTIBLE_DIA
            oxigeno = oxigeno - consumo_oxigeno
            energia = energia - CONSUMO_ENERGIA_DIA
            provisiones = provisiones - consumo_provisiones
            dias_transcurridos = dias_transcurridos + 1
            print("Día", dias_transcurridos, "| Combustible:", combustible, "| Oxígeno:", oxigeno,
                  "| Energía:", energia, "| Provisiones:", provisiones)
        else:
            puede_continuar = False

    if puede_continuar:
        print("La tripulación regresó exitosamente a la Tierra.")
        print("Combustible restante:", combustible, "unidades")
        print("Oxígeno restante:", oxigeno, "unidades")
        print("Energía restante:", energia, "unidades")
        print("Provisiones restantes:", provisiones, "unidades")
    else:
        print("El regreso se interrumpió en el día", str(dias_transcurridos + 1) + ".")
        if oxigeno < consumo_oxigeno:
            print("Recurso insuficiente: oxígeno")
        if energia < CONSUMO_ENERGIA_DIA:
            print("Recurso insuficiente: energía")
        if provisiones < consumo_provisiones:
            print("Recurso insuficiente: provisiones")
        print("La tripulación no completó el regreso.")
else:
    # ----- Caso B: tripulación varada -----
    print("La tripulación quedó varada en el destino.")
    dias_oxigeno = oxigeno // consumo_oxigeno
    dias_energia = energia // CONSUMO_ENERGIA_DIA
    dias_provisiones = provisiones // consumo_provisiones

    # Mínimo de los tres resultados obtenido con condicionales.
    supervivencia = dias_oxigeno
    if dias_energia < supervivencia:
        supervivencia = dias_energia
    if dias_provisiones < supervivencia:
        supervivencia = dias_provisiones

    # Se construye el texto de los recursos limitantes, incluidos los empates.
    limitantes = ""
    if dias_oxigeno == supervivencia:
        limitantes = "oxígeno"
    if dias_energia == supervivencia:
        if limitantes != "":
            limitantes = limitantes + ", "
        limitantes = limitantes + "energía"
    if dias_provisiones == supervivencia:
        if limitantes != "":
            limitantes = limitantes + ", "
        limitantes = limitantes + "provisiones"

    print("Días por oxígeno:", dias_oxigeno)
    print("Días por energía:", dias_energia)
    print("Días por provisiones:", dias_provisiones)
    print("Supervivencia estimada:", supervivencia, "días")
    print("Recurso(s) limitante(s):", limitantes)
Explicación: El mínimo se obtiene comparando con < (no <=), así el valor solo cambia cuando hay uno estrictamente menor. Los limitantes se comparan con == contra el mínimo usando condicionales simples, para incluir todos los empates en el orden oxígeno, energía, provisiones.
