De procedimiento a función

En la actividad anterior, cada procedimiento leía sus datos y mostraba su resultado. Una función con parámetros y return trabaja distinto: recibe los datos en sus parámetros y devuelve el resultado a quien la llamó, que puede guardarlo en una variable y usarlo después.

# Procedimiento (sin parámetros ni return): lee, calcula y muestra
def calcular_area_rectangulo():
    base = float(input("Base: "))
    altura = float(input("Altura: "))
    print("Área:", base * altura)


# Función con parámetros y return: recibe los datos y DEVUELVE el resultado
def calcular_area(base, altura):
    area = base * altura
    return area


area_sala = calcular_area(5, 4)        # area_sala guarda 20
area_cocina = calcular_area(3, 2.5)    # area_cocina guarda 7.5
print("Área total:", area_sala + area_cocina)
  • base y altura son los parámetros: variables que reciben los valores de la llamada.
  • En calcular_area(5, 4), los valores 5 y 4 son los argumentos.
  • return area devuelve el valor: la llamada calcular_area(5, 4) se reemplaza por 20.
  • Como la función devuelve el valor en lugar de mostrarlo, el resultado se puede reutilizar: aquí se suman dos áreas.
En el diagrama: En el diagrama de flujo, el inicio indica el nombre y los parámetros (Inicio calcular_area(base, altura)) y el fin indica el valor que devuelve (Fin: devolver area). La llamada se dibuja con el símbolo de proceso predefinido, incluida la variable que recibe el valor: area_sala = calcular_area(5, 4).

Situación: la caminata espacial

Antes de que los astronautas salgan de la nave a una caminata espacial, el sistema debe verificar si el oxígeno de los trajes alcanza. Cada astronauta consume 2 unidades de oxígeno por minuto y siempre deben quedar 20 unidades de reserva.

Declare estas constantes al inicio del archivo:

CONSUMO_OXIGENO_MINUTO = 2     # unidades por astronauta por minuto
RESERVA_OXIGENO = 20           # unidades que siempre deben quedar de reserva
MARGEN_SEGURO = 30             # margen mínimo para considerar la caminata segura

Programa completo:

# ============================================================
# Archivo: caminata_espacial.py
# Descripción: Verifica si el oxígeno alcanza para una caminata
#              espacial, usando funciones con parámetros y return.
# ============================================================
CONSUMO_OXIGENO_MINUTO = 2     # unidades por astronauta por minuto
RESERVA_OXIGENO = 20           # unidades que siempre deben quedar de reserva
MARGEN_SEGURO = 30             # margen mínimo para considerar la caminata segura


def calcular_oxigeno_requerido(minutos, astronautas):
    """Devuelve el oxígeno requerido para la caminata, incluida la reserva."""
    requerido = minutos * astronautas * CONSUMO_OXIGENO_MINUTO + RESERVA_OXIGENO
    return requerido


def oxigeno_alcanza(disponible, requerido):
    """Devuelve True si el oxígeno disponible es mayor o igual que el requerido."""
    alcanza = disponible >= requerido
    return alcanza


def calcular_minutos_maximos(disponible, astronautas):
    """Devuelve los minutos completos que se pueden caminar sin tocar la reserva (0 si no alcanza ni la reserva)."""
    if disponible < RESERVA_OXIGENO:
        minutos = 0
    else:
        minutos = (disponible - RESERVA_OXIGENO) // (astronautas * CONSUMO_OXIGENO_MINUTO)
    return minutos


def clasificar_margen(disponible, requerido):
    """Devuelve 'Insuficiente', 'Bajo' o 'Seguro' según el margen de oxígeno."""
    margen = disponible - requerido
    if margen < 0:
        clasificacion = "Insuficiente"
    elif margen < MARGEN_SEGURO:
        clasificacion = "Bajo"
    else:
        clasificacion = "Seguro"
    return clasificacion


def main():
    """Programa principal: guarda en variables los valores que devuelven las funciones."""
    astronautas = int(input("Cantidad de astronautas: "))
    minutos = int(input("Duración de la caminata (minutos): "))
    disponible = int(input("Oxígeno disponible: "))
    requerido = calcular_oxigeno_requerido(minutos, astronautas)
    clasificacion = clasificar_margen(disponible, requerido)
    minutos_maximos = calcular_minutos_maximos(disponible, astronautas)
    print("Oxígeno requerido:", requerido)
    print("Margen de oxígeno:", clasificacion)
    if oxigeno_alcanza(disponible, requerido):
        print("Caminata autorizada.")
    else:
        print("Caminata no autorizada.")
    print("Tiempo máximo posible:", minutos_maximos, "minutos")


main()

def leer_entero_positivo(mensaje):
    """Lee un entero con el mensaje indicado; lo vuelve a pedir mientras sea menor que 1. Devuelve el entero."""
    valor = int(input(mensaje))
    while valor < 1:
        print("El valor debe ser mayor que 0.")
        valor = int(input(mensaje))
    return valor


def calcular_oxigeno_requerido(minutos, astronautas):
    """Devuelve el oxígeno requerido para la caminata, incluida la reserva."""

def mostrar_reporte(requerido, clasificacion, autorizada, minutos_maximos):

    print("Oxígeno requerido:", requerido)
    print("Margen de oxígeno:", clasificacion)
    if autorizada:
        print("Caminata autorizada.")
    else:
        print("Caminata no autorizada.")
    print("Tiempo máximo posible:", minutos_maximos, "minutos")


def main():
    """Programa principal: guarda en variables los valores que devuelven las funciones."""
