Una lista es una fila de casillas numeradas

Una lista guarda varios valores en una sola variable. Cada valor ocupa una casilla y cada casilla tiene un número llamado índice (posición).

frutas = ["mango", "piña", "papaya", "banano", "fresa"]

ÍndiceÍndice negativo
0 "mango" -5
1 "piña" -4
2 "papaya" -3
3 "banano" -2
4 "fresa" -1
  • El primer elemento está en el índice 0, no en el 1.
  • El último índice es la cantidad de elementos − 1. Esta lista tiene 5 elementos: sus índices van de 0 a 4.
  • Para leer un elemento se escribe el nombre de la lista y el índice entre corchetes: frutas[1] es "piña".
  • Los índices negativos cuentan desde el final: frutas[-1] es el último elemento.
  • len(frutas) devuelve la cantidad de elementos: 5.
  • Si se usa un índice que no existe, por ejemplo frutas[7], Python muestra el error IndexError.
Cómo responder: Escriba solo el valor, sin comillas (por ejemplo: mango). Si la instrucción produce un error, escriba error. Presione Revisar o la tecla Enter para comprobar cada respuesta.

Parte 3: La lista cambia

Las instrucciones se ejecutan en orden, de arriba hacia abajo, a partir de esta lista:

colores = ["rojo", "azul", "verde"]

ÍndiceÍndice negativo
0 "rojo" -3
1 "azul" -2
2 "verde" -1 
colores.append("negro")   # instrucción A
colores.pop(0)            # instrucción B
colores[1] = "blanco"     # instrucción C
  • append(valor) agrega el valor en una casilla nueva al final.
  • pop(indice) elimina el elemento de esa posición; los elementos que estaban después se corren una posición hacia la izquierda.
  • lista[indice] = valor reemplaza el valor de esa casilla.

Recuerde: el primer índice es 0 y el último es len(lista) - 1; los índices negativos cuentan desde el final; append() agrega al final, pop() elimina y corre los elementos siguientes, y lista[i] = valor reemplaza el contenido de una casilla.
