Ejercicio: Prueba de escritorio (traza)

Instrucciones: Seleccione al menos uno de los programas propuestos y realice su prueba de escritorio: simule a mano la ejecución, línea por línea, registrando en una tabla el valor de las variables, el resultado de las condiciones y la salida en pantalla. Luego compruebe su traza ejecutando el programa.

¿Cómo se hace una prueba de escritorio?

Una prueba de escritorio (o traza) consiste en ejecutar el programa a mano, línea por línea, anotando en una tabla cómo cambian las variables. Ejemplo:

1precio = 5000
2cantidad = 3
3total = precio * cantidad
4if total > 10000:
5    total = total - 1000
6print("Total:", total)

Traza:

Paso Línea Instrucción precio cantidad total Condición Salida
1 1 precio = 5000 5000        
2 2 cantidad = 3   3      
3 3 total = precio * cantidad     15000    
4 4 if total > 10000:       Verdadero  
5 5 total = total - 1000     14000    
6 6 print("Total:", total)         Total: 14000
  • Cada fila es una línea que se ejecuta. Las líneas que se saltan no aparecen.
  • En las columnas de variables se anota el valor solo cuando la variable cambia.
  • En la columna Condición se anota si la condición del if es verdadera o falsa.
  • En la columna Salida se anota lo que muestra print().

Programa 1: Costo de un envío Condicionales

Una empresa de mensajería cobra ₡2 500 por paquete. Si el paquete pesa más de 5 kg, se cobran ₡800 por cada kilogramo adicional. Los envíos internacionales cuestan el triple.

1peso = float(input("Peso del paquete (kg): "))
2destino = input("Destino (N = nacional, I = internacional): ")
3costo = 2500
4if peso > 5:
5    costo = costo + (peso - 5) * 800
6if destino == "I":
7    costo = costo * 3
8elif destino != "N":
9    costo = 0
10    print("Destino no válido")
11print("Costo del envío:", costo)

Datos de prueba:

  • Conjunto A: peso = 3, destino = N
  • Conjunto B: peso = 8, destino = I
  • Conjunto C: peso = 2, destino = X

Preguntas:

  1. Con el conjunto A, ¿qué líneas del programa no se ejecutan?
  2. Con el conjunto C, ¿por qué el programa muestra "Costo del envío: 0" después del mensaje de error? ¿Es correcto?
  3. ¿Por qué la condición de la línea 8 no se evalúa con el conjunto B?
Programa 2: Año bisiesto Operadores lógicos

Un año es bisiesto si es divisible entre 4 y no entre 100, o si es divisible entre 400.

1anio = int(input("Año: "))
2divisible_4 = anio % 4 == 0
3divisible_100 = anio % 100 == 0
4divisible_400 = anio % 400 == 0
5if (divisible_4 and not divisible_100) or divisible_400:
6    print(anio, "es bisiesto")
7else:
8    print(anio, "no es bisiesto")

Datos de prueba:

  • Conjunto A: anio = 2024
  • Conjunto B: anio = 1900
  • Conjunto C: anio = 2000

Preguntas:

  1. ¿Qué valor (True o False) tiene cada variable booleana en cada conjunto?
  2. Evalúe la condición de la línea 5 por partes: primero el paréntesis y luego el or.
  3. ¿Por qué 1900 no es bisiesto si es divisible entre 4?
Programa 3: El mayor de tres números Condicionales

El programa determina cuál es el mayor de tres números enteros.

1a = int(input("Primer número: "))
2b = int(input("Segundo número: "))
3c = int(input("Tercer número: "))
4mayor = a
5if b > mayor:
6    mayor = b
7if c > mayor:
8    mayor = c
9print("El mayor es:", mayor)

Datos de prueba:

  • Conjunto A: a = 4, b = 9, c = 2
  • Conjunto B: a = 7, b = 7, c = 3
  • Conjunto C: a = -1, b = -5, c = -3

Preguntas:

  1. ¿Cuántas veces cambia el valor de mayor en cada conjunto?
  2. Con el conjunto B, ¿se ejecuta la línea 6? ¿Por qué?
  3. Si en la línea 4 se escribiera mayor = 0, ¿qué mostraría el programa con el conjunto C?
Programa 4: Cajero automático Secuencial

Un cajero entrega el monto solicitado usando la menor cantidad de billetes de ₡10 000, ₡5 000 y ₡1 000.

1monto = int(input("Monto a retirar: "))
2billetes_10000 = monto // 10000
3resto = monto % 10000
4billetes_5000 = resto // 5000
5resto = resto % 5000
6billetes_1000 = resto // 1000
7resto = resto % 1000
8print("Billetes de 10 000:", billetes_10000)
9print("Billetes de 5 000:", billetes_5000)
10print("Billetes de 1 000:", billetes_1000)
11print("Monto no entregado:", resto)

Datos de prueba:

  • Conjunto A: monto = 37000
  • Conjunto B: monto = 12500
  • Conjunto C: monto = 4300

Preguntas:

  1. ¿Qué representa la variable resto en cada momento? ¿Por qué cambia de valor tres veces?
  2. ¿Qué diferencia hay entre los operadores // y %?
  3. ¿Qué monto produce la mayor cantidad de billetes de ₡1 000 posible? Compruébelo con la traza.
