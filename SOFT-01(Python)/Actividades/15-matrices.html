Una matriz es una lista de listas

Una matriz organiza datos en filas y columnas. En Python se escribe como una lista cuyos elementos también son listas: cada lista interna es una fila.

La siguiente matriz guarda las notas de tres estudiantes en tres evaluaciones:

notas = [[80, 90, 75],
         [60, 70, 65],
         [95, 85, 100]]
fila ↓ / col →012Estudiante
0809075Ana
1607065Luis
29585100Sofía
  • Para leer un valor se escriben dos índices: primero la fila y luego la columna. notas[0][1] es la fila 0, columna 1.
  • Las filas y las columnas empiezan en 0, igual que en las listas.
  • notas[2] (un solo índice) es la fila completa: una lista.
  • len(notas) es la cantidad de filas y len(notas[0]) es la cantidad de columnas de la fila 0.
