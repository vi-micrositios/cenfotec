Ejercicio: Diseñando programas que repiten acciones con ciclos

Instrucciones: Seleccione uno de los contextos propuestos y desarrolle una solución que utilice variables, constantes, flujo secuencial, estructuras condicionales y ciclos (for o while). Primero represente la solución mediante un diagrama de flujo, luego diseñe los casos de prueba y finalmente impleméntela en Python.

Seleccione un contexto

Seleccione uno de los siguientes contextos y desarrolle una solución utilizando variables, constantes, operaciones aritméticas, flujo secuencial, estructuras condicionales y al menos un ciclo.

Cajero automático

Un cajero automático permite al usuario realizar varios retiros consecutivos sobre un mismo saldo inicial hasta que decida salir o hasta que no tenga fondos suficientes. El saldo inicial de la cuenta es de ₡250 000.

El programa debe solicitar:

  • Monto a retirar en cada operación.
  • Confirmación para continuar retirando (s / n).

Utilice las siguientes reglas:

  • El retiro mínimo por operación es de ₡5 000.
  • El retiro máximo por operación es de ₡100 000.
  • Si el monto supera el saldo disponible, no se realiza el retiro y se muestra un mensaje.
  • El ciclo continúa mientras el usuario escriba "s" y exista saldo disponible.
  • Al finalizar, se muestra el saldo restante y la cantidad de retiros exitosos.
El programa debe mostrar: por cada intento, si el retiro se realizó o no, el saldo actualizado, y al final el saldo restante y el total de retiros exitosos.
Registro de notas de un curso

Un profesor desea calcular el promedio de notas de un grupo de estudiantes. No sabe de antemano cuántos estudiantes hay, pero sí sabe que la cantidad máxima es 30.

El programa debe solicitar:

  • Nota del estudiante (entre 0 y 100).
  • Continuar o finalizar el ingreso (s / n).

Utilice las siguientes reglas:

  • El ciclo se repite mientras el profesor ingrese "s" y no se superen 30 estudiantes.
  • Si la nota es menor a 0 o mayor a 100, se muestra error y no se cuenta.
  • Se debe llevar la cantidad de aprobados (nota ≥ 70) y la cantidad de reprobados.
  • Al salir, se calcula el promedio de todas las notas válidas.
  • Si no se ingresó ninguna nota válida, se muestra un mensaje de advertencia.
El programa debe mostrar: cantidad de notas ingresadas, cantidad de aprobados, cantidad de reprobados, promedio del grupo y mensaje de advertencia si no hubo datos.
Inventario de una tienda

Una tienda desea registrar el inventario de sus productos. El sistema debe permitir ingresar productos hasta que el usuario decida terminar.

El programa debe solicitar:

  • Nombre del producto.
  • Precio unitario.
  • Cantidad en existencia.
  • Indicar si desea continuar (s / n).

Utilice las siguientes reglas:

  • El ciclo se ejecuta mientras el usuario ingrese "s".
  • Si el precio es menor o igual a cero, se muestra error y no se registra el producto.
  • Si la cantidad es menor a 5, el producto se marca como "requiere reposición".
  • Se acumula el valor total del inventario (precio × cantidad).
  • Al finalizar, se muestra el valor total, cuántos productos se registraron y cuántos requieren reposición.
El programa debe mostrar: el valor total del inventario, la cantidad total de productos registrados y la cantidad de productos que requieren reposición.
Simulador de ahorro con interés compuesto

Un usuario desea simular cómo crece su ahorro mes a mes aplicando un interés compuesto. El usuario define un ahorro inicial y una tasa mensual, y el programa muestra la evolución del saldo hasta alcanzar una meta.

El programa debe solicitar:

  • Ahorro inicial (₡).
  • Aporte mensual fijo (₡).
  • Tasa de interés mensual (%).
  • Meta de ahorro (₡).

Utilice las siguientes reglas:

  • El ciclo se repite mientras el saldo sea menor a la meta y no hayan pasado más de 120 meses.
  • En cada mes: primero se suma el interés (saldo × tasa), luego se suma el aporte mensual.
  • Se debe mostrar el saldo al final de cada mes (o cada 12 meses si el usuario así lo prefiere).
  • Si se alcanza la meta, se indica en qué mes se logró.
  • Si pasan 120 meses sin alcanzarla, se indica cuánto faltó.
El programa debe mostrar: la evolución mensual (o anual) del ahorro, el mes en que se alcanza la meta (si se alcanza) y el saldo final en cualquiera de los dos escenarios.
Facturación de un restaurante

Un restaurante desea generar la factura de un cliente que ordena varios platos y bebidas. El mesero ingresa cada producto y al final se imprime el total con impuesto y propina.

El programa debe solicitar:

  • Nombre del producto.
  • Precio unitario.
  • Cantidad.
  • Tipo: plato fuerte (P) o bebida (B).
  • Indicar si desea seguir agregando productos (s / n).

Utilice las siguientes reglas:

  • El ciclo se ejecuta mientras el mesero ingrese "s".
  • Se acumula el subtotal de todos los productos.
  • Si el subtotal es mayor o igual a ₡20 000, se aplica un 10 % de descuento.
  • Sobre el monto con descuento se aplica un 13 % de IVA.
  • Sobre el monto final se puede aplicar opcionalmente una propina del 10 % si el cliente lo indica.
  • Se debe llevar el conteo de platos fuertes y bebidas.
El programa debe mostrar: la cantidad de platos fuertes y bebidas, el subtotal, el descuento, el IVA, la propina (si aplica) y el total a pagar.

Parte 2: Diseñar el diagrama de flujo con ciclos

Antes de programar, represente gráficamente la solución mediante un diagrama de flujo que incluya explícitamente el uso de un ciclo.

El diagrama debe mostrar:

  • Inicio y finalización del programa.
  • Entrada de datos dentro y fuera del ciclo.
  • Procesos, acumuladores y contadores.
  • Constantes utilizadas.
  • Decisiones y sus diferentes caminos.
  • El ciclo claramente identificado: punto de entrada, condición de continuación y flecha de retorno.
  • La variable que controla la salida del ciclo (contador o bandera).
  • Resultados mostrados al usuario al terminar el ciclo.
Recomendación: indique junto al ciclo qué tipo usó (for o while) y justifique brevemente por qué ese tipo es el más adecuado para el contexto elegido.

Parte 4: Implementar la solución en Python

Transforme el diagrama de flujo en un programa funcional utilizando Python. Cuando lo ejecute, use los casos de prueba de la Parte 3 para completar las columnas resultado real y ¿coincide?.

El programa debe utilizar:

  • Variables para almacenar los datos que pueden cambiar.
  • Constantes para los valores que representan reglas del problema.
  • Operaciones aritméticas cuando sean necesarias.
  • Flujo secuencial.
  • Al menos una estructura if / else.
  • Al menos un ciclo (for, while) con su condición de salida bien definida.
  • Un acumulador o contador que se actualice dentro del ciclo.

Parte 5: Aplicar convenciones y estilos adecuados

Revise el programa antes de realizar las pruebas y compruebe que el código sea claro y fácil de comprender.

  • Utilice nombres de variables descriptivos.
  • Utilice constantes con nombres en mayúsculas.
  • Mantenga una indentación adecuada dentro del ciclo.
  • Evite repetir valores que deberían estar definidos como constantes.
  • Muestre mensajes claros al usuario dentro y fuera del ciclo.
  • Asegúrese de que el ciclo tenga una condición de salida alcanzable.
  • Mantenga el código sencillo y legible.
