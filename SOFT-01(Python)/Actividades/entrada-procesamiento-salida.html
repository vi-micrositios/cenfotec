Ejercicio 3: Programa en Python — Entrada, procesamiento y salida

Instrucciones: Analizar la situación planteada, proponer el algoritmo correspondiente mediante un diagrama de flujo y posteriormente desarrollar el programa en Python. Los datos de entrada y los resultados deberán almacenarse en variables.

Situación planteada

Una tienda desea calcular cuánto debe pagar un cliente por un producto. El programa debe solicitar el nombre del producto, el precio unitario y la cantidad de unidades.

Con estos datos, el programa debe calcular el total a pagar y mostrar la información al usuario.

Parte 1: Proponer el algoritmo mediante un diagrama de flujo

Antes de escribir el código en Python, diseñe un diagrama de flujo que represente paso a paso la solución del problema.

El diagrama debe incluir como mínimo:

  • Inicio del algoritmo.
  • Solicitud de los datos de entrada.
  • Almacenamiento de los datos en variables.
  • Proceso para calcular el total a pagar.
  • Almacenamiento del resultado en una variable.
  • Presentación de los resultados.
  • Fin del algoritmo.
Recuerde: Utilice correctamente los símbolos de un diagrama de flujo: óvalo para inicio y fin, paralelogramo para entrada y salida, y rectángulo para los procesos.

Parte 2: Datos de entrada

El programa debe solicitar los siguientes datos y almacenarlos en variables:

  • Nombre del producto.
  • Precio unitario.
  • Cantidad de unidades.

Parte 3: Procesamiento

Realice el cálculo del total multiplicando el precio unitario por la cantidad. El resultado debe almacenarse en una variable llamada total.

Parte 4: Crear el programa en Python

Transforme el diagrama de flujo en un programa funcional utilizando Python. El programa debe:

  • Utilizar input() para solicitar los datos.
  • Guardar cada dato ingresado en una variable.
  • Utilizar int() o float() cuando sea necesario.
  • Realizar el cálculo y guardar el resultado en una variable.
  • Utilizar print() para mostrar los resultados.

Parte 5: Datos de salida

El programa debe mostrar:

  • Nombre del producto.
  • Precio unitario.
  • Cantidad comprada.
  • Total a pagar.
Reto: Modifique el algoritmo y el programa para incluir un porcentaje de descuento. El descuento y el precio final también deberán almacenarse en variables.
