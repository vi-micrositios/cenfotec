Ejercicio: Pruebas y corrección de errores en Python

Instrucciones: Analizar el problema planteado, diseñar casos de prueba antes de modificar el programa, ejecutar las pruebas sobre el código proporcionado, identificar el error, corregirlo y volver a ejecutar las pruebas para comprobar que el programa funciona correctamente.

Situación planteada

Un programador ha desarrollado un programa que debe calcular el precio final de un producto aplicando un descuento del 10 %. El programa solicita al usuario el precio original y posteriormente muestra el precio con descuento.

p = float(input("Precio: "))
d = 10
pf = p - d
print("Precio final:", pf)

Parte 1: Diseñar los casos de prueba (CP)

Antes de ejecutar el programa, diseñe al menos cuatro casos de prueba que permitan comprobar diferentes datos de entrada.

Los casos de prueba deben incluir como mínimo:

  • Un caso normal.
  • Un caso límite.
  • Un caso inválido.
  • Un caso extremo.

Utilice la siguiente estructura:

N.º Tipo de CP Entrada (datos de la prueba) Salida esperada Resultado de la prueba
1
Importante: La columna “Resultado de la prueba” deberá completarse después de ejecutar el código original. No debe confundirse con la salida esperada.

Parte 2: Ejecutar las pruebas sobre el código original

Ejecute el programa proporcionado utilizando los datos definidos en cada caso de prueba.

Registre en la tabla el resultado obtenido realmente por el programa y compárelo con la salida esperada.

Parte 3: Identificar y explicar el error

A partir de los resultados obtenidos, determine por qué el programa no produce los resultados esperados.

Parte 4: Corregir el código

Corrija el programa para que aplique correctamente el descuento del 10 %.

Parte 5: Aplicar convenciones y estilos adecuados

Una vez corregido el algoritmo, mejore el código aplicando buenas prácticas de programación en Python.

  • Utilizar nombres de variables descriptivos.
  • Utilizar snake_case o camelCase para las variables.
  • Mantener una indentación y espaciado adecuados.
  • Mostrar mensajes claros al usuario.
  • Mantener el código sencillo y legible.

Parte 6: Reejecutar las pruebas

Ejecute nuevamente todos los casos de prueba utilizando el código corregido.

Para cada caso, indique si:

  • La salida obtenida coincide con la salida esperada.
  • La prueba fue exitosa o fallida.
  • Es necesario realizar algún ajuste adicional al programa.
Conclusión: Un programa no se considera correctamente corregido únicamente porque el código pueda ejecutarse. Es necesario comprobar mediante casos de prueba que los resultados obtenidos coincidan con los resultados esperados.
Opcional (para quienes conocen de condicionales): Modifique el programa para que el usuario pueda ingresar el porcentaje de descuento. Agregue validaciones para impedir precios negativos y controlar entradas que no sean numéricas. Diseñe nuevos casos de prueba para comprobar estas validaciones.
