Ejercicio: Crear un repositorio Git y publicar las soluciones de clase

Objetivo: aplicar los conceptos básicos de Git y GitHub para crear un repositorio, organizar archivos, registrar cambios mediante commits y publicar las soluciones de los ejercicios desarrollados durante las clases.

Situación planteada

Durante las clases se han desarrollado diferentes ejercicios relacionados con los contenidos estudiados. Ahora deberá organizar y publicar estas soluciones utilizando un sistema de control de versiones.

Para realizar la actividad deberá crear un repositorio en GitHub, preparar una estructura organizada para almacenar los ejercicios y subir los archivos utilizando Git.

Crear y configurar el repositorio

Realice el proceso completo para crear el repositorio y preparar los archivos de los ejercicios desarrollados en clase.

El repositorio deberá cumplir con las siguientes condiciones:

  • Tener un nombre relacionado con el curso.
  • Contener una carpeta denominada ejercicios.
  • Contener dentro de dicha carpeta las soluciones realizadas durante las clases.
  • Contener un archivo README.md: Con al menos la descripción del curso, la sección y una lista de archivos .py. 
  • Utilizar nombres de archivos claros y descriptivos.
  • Mantener una estructura ordenada y fácil de comprender.
Pregunta clave: ¿Qué ventajas tiene guardar todos los ejercicios en un repositorio en lugar de mantenerlos únicamente en una carpeta de su computadora?

Resolver un problema utilizando condicionales y operadores lógicos

Elabore un programa en Python que permita determinar si un estudiante puede acceder a una beca según su promedio, porcentaje de asistencia y participación en un programa de apoyo institucional.

Una institución educativa desea determinar si un estudiante puede acceder a una beca estudiantil. Para ello, se deben considerar su promedio académico, su porcentaje de asistencia y si pertenece a un programa de apoyo institucional.

El estudiante obtiene la beca si cumple alguna de las siguientes condiciones:

  1. Tener un promedio igual o superior a 80 y una asistencia igual o superior al 85%.
  2. Pertenecer a un programa de apoyo institucional y tener una asistencia igual o superior al 75%.

Si el estudiante no cumple ninguna de las dos condiciones, no obtiene la beca.

Datos que debe solicitar el programa
  • Promedio académico: valor entre 0 y 100.
  • Porcentaje de asistencia: valor entre 0 y 100.
  • Programa de apoyo: indicar si el estudiante pertenece o no a un programa de apoyo institucional.

La solución deberá:

  • Estar desarrollada en un archivo .py.
  • Utilizar estructuras condicionales como if, elif y/o else.
  • Utilizar los operadores lógicos and y or.
  • Solicitar los datos necesarios mediante entrada por teclado.
  • Mostrar claramente si el estudiante obtiene o no la beca.
  • Utilizar nombres de variables claros y descriptivos.
  • Incluir comentarios que faciliten la comprensión del código.
  • Guardar el archivo dentro de la carpeta ejercicios del repositorio.
Ejemplos de resultados
  • Promedio: 85, asistencia: 90%, programa de apoyo: no → Obtiene la beca.
  • Promedio: 75, asistencia: 90%, programa de apoyo: no → No obtiene la beca.
  • Promedio: 70, asistencia: 80%, programa de apoyo: sí → Obtiene la beca.
  • Promedio: 70, asistencia: 70%, programa de apoyo: sí → No obtiene la beca.
Importante: Después de resolver el problema, deberá agregar el archivo al repositorio, realizar un commit descriptivo y subir los cambios a GitHub.
