Ejercicios adicionales: Programación secuencial

Instrucciones generales

Para cada uno de los siguientes problemas deberá realizar el proceso completo de solución de un problema mediante programación.

  1. Analizar el problema: determine qué información necesita el programa (datos de entrada) y qué resultado debe obtener (datos de salida).
  2. Identificar el proceso: determine las variables y operaciones necesarias para resolver el problema.
  3. Construir el diagrama de flujo: represente gráficamente el algoritmo para solucionar el problema.
  4. Programar en Python: convierta el algoritmo en un programa.
  5. Probar el programa: utilice diferentes datos de entrada y compruebe que los resultados sean correctos.

Salario de un trabajador

Una empresa desea calcular el salario semanal de uno de sus trabajadores. El programa debe solicitar el nombre del trabajador, la cantidad de horas trabajadas durante la semana y el pago recibido por cada hora trabajada.

Con esta información, el programa debe calcular el salario semanal y mostrar el nombre del trabajador, las horas trabajadas, el pago por hora y el salario obtenido.

Fórmula: salario = horas trabajadas × pago por hora

Área y perímetro de un rectángulo

Una aplicación necesita calcular las dimensiones de un rectángulo. El programa debe solicitar el largo y el ancho de la figura.

Con estos datos debe calcular y mostrar el área y el perímetro del rectángulo.

Fórmulas:
área = largo × ancho
perímetro = 2 × (largo + ancho)

Promedio de calificaciones

Un estudiante desea conocer el promedio obtenido en un curso. El programa debe solicitar el nombre del estudiante y las calificaciones obtenidas en tres evaluaciones.

El programa debe calcular el promedio de las tres calificaciones y mostrar el nombre del estudiante, cada una de las calificaciones y el promedio final.

Fórmula: promedio = (nota1 + nota2 + nota3) / 3

Consumo de combustible

Una persona desea calcular cuánto dinero necesitará para comprar combustible para realizar un viaje.

El programa debe solicitar la distancia del viaje en kilómetros, el rendimiento del vehículo en kilómetros por litro y el precio de un litro de combustible.

Debe calcular la cantidad aproximada de litros necesarios para realizar el viaje y el costo total del combustible.

Fórmulas:
litros necesarios = distancia / rendimiento
costo = litros necesarios × precio por litro

Factura de un restaurante

Un restaurante desea calcular el monto que debe pagar un cliente. El programa debe solicitar el nombre del cliente, el nombre del plato, el precio del plato y la cantidad de platos solicitados.

Además, el restaurante cobra un impuesto del 13 %. El programa debe calcular el subtotal, el monto del impuesto y el total que debe pagar el cliente.

Fórmulas:
subtotal = precio × cantidad
impuesto = subtotal × 13 / 100
total = subtotal + impuesto

Compra con descuento

Una tienda de ropa desea calcular el precio final de una compra. El programa debe solicitar el nombre del cliente, el nombre del producto, el precio del producto, la cantidad comprada y el porcentaje de descuento.

El programa debe calcular el subtotal de la compra, el monto correspondiente al descuento y el precio final que debe pagar el cliente.

Fórmulas:
subtotal = precio × cantidad
descuento = subtotal × porcentaje / 100
total = subtotal - descuento

Conversión de temperatura

Una aplicación meteorológica necesita convertir una temperatura expresada en grados Celsius a grados Fahrenheit.

El programa debe solicitar el nombre de la persona y la temperatura en grados Celsius. Luego debe calcular y mostrar la temperatura equivalente en grados Fahrenheit.

Fórmula: Fahrenheit = (Celsius × 9 / 5) + 32

Conversión de moneda

Una persona desea conocer cuánto dinero recibirá en colones al cambiar una cantidad de dólares.

El programa debe solicitar el nombre de la persona, la cantidad de dólares que desea convertir y el tipo de cambio.

Debe calcular y mostrar la cantidad equivalente en colones.

Fórmula: colones = dólares × tipo de cambio

Reservación de hotel

Un hotel desea calcular el costo total de una reservación. El programa debe solicitar el nombre del cliente, la cantidad de noches, el precio por noche y el porcentaje de impuesto.

Con estos datos debe calcular el subtotal de la reservación, el monto correspondiente al impuesto y el total que deberá pagar el cliente.

Fórmulas:
subtotal = noches × precio por noche
impuesto = subtotal × porcentaje / 100
total = subtotal + impuesto

Salario con deducción

Una empresa desea calcular cuánto dinero recibirá finalmente un trabajador después de aplicar una deducción a su salario.

El programa debe solicitar el nombre del trabajador, la cantidad de horas trabajadas, el pago por hora y el porcentaje de deducción.

Debe calcular el salario bruto, el monto de la deducción y el salario neto. Finalmente, debe mostrar toda la información al usuario.

Fórmulas:
salario bruto = horas × pago por hora
deducción = salario bruto × porcentaje / 100
salario neto = salario bruto - deducción
Recuerde: antes de escribir código, analice el problema. Identifique las entradas, los procesos y las salidas; determine las variables necesarias; construya el diagrama de flujo y, finalmente, implemente la solución en Python.
