Procedimientos: Calculadora de áreas

Objetivo: aplicar la abstracción procedimental para implementar en Python un programa organizado en procedimientos sin parámetros y sin valor de retorno, representarlo mediante diagramas de flujo y comprobar su funcionamiento con casos de prueba.

En esta actividad programará una calculadora de áreas dividida en procedimientos.

Programe la calculadora de áreas

Escriba en Visual Studio Code un programa que calcule áreas de figuras usando procedimientos sin parámetros y sin return.

  1. Declare las constantes PI = 3.1416 y OPCION_SALIR = 4 al inicio del archivo.
  2. Programe estos cinco procedimientos, con estos nombres exactos:
    • mostrar_encabezado(): muestra el título «CALCULADORA DE ÁREAS» entre dos líneas de signos =.
    • mostrar_menu(): muestra «1. Rectángulo», «2. Triángulo», «3. Círculo» y «4. Salir», una opción por línea.
    • calcular_area_rectangulo(): lee la base y la altura, calcula base * altura y muestra «Área del rectángulo: <área>».
    • calcular_area_triangulo(): lee la base y la altura, calcula base * altura / 2 y muestra «Área del triángulo: <área>».
    • calcular_area_circulo(): lee el radio, calcula PI * radio * radio y muestra «Área del círculo: <área>», con el área redondeada a 2 decimales.
  3. Programe main(): primero llama a mostrar_encabezado(); después repite el menú hasta que el usuario elija la opción 4 y, en cada vuelta, llama al procedimiento que corresponde a la opción elegida. Si la opción no es 1, 2, 3 ni 4, muestra «Opción no válida.».
  4. Al salir del ciclo, main() muestra «Gracias por usar la calculadora.».
  5. La última línea del archivo es la llamada main().
  6. Ningún procedimiento recibe parámetros ni usa return. Los datos se leen como números decimales (float).
