Ejemplo: Prueba de escritorio

El objetivo del siguiente algoritmo es sumar los números del 1 al 3 utilizando un ciclo while. 

contador = 1
suma = 0

while contador <= 3:
    suma = suma + contador
    contador = contador + 1

print("La suma es:", suma)

Prueba de escitorio / traza:

Iteración Variables de control (antes) Condición evaluada ¿Entra al ciclo? Cálculos / actualizaciones Acumuladores (después) Salida mostrada
1 contador = 1 1 <= 3 → Verdadero Sí suma = 0 + 1
contador = 1 + 1		 suma = 1 —
2 contador = 2 2 <= 3 → Verdadero Sí suma = 1 + 2
contador = 2 + 1		 suma = 3 —
3 contador = 3 3 <= 3 → Verdadero Sí suma = 3 + 3
contador = 3 + 1		 suma = 6 —
4 contador = 4 4 <= 3 → Falso No No se ejecuta el cuerpo del ciclo suma = 6 La suma es: 6
La última fila representa la evaluación que permite salir del ciclo. Aunque no se realiza una nueva iteración, es importante registrar la condición falsa y la salida final del programa.
