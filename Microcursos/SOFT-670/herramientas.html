Las siguientes herramientas son fundamentales para el desarrollo con Python y el trabajo en ciencia de datos. Su instalación y uso son recomendados para el desarrollo de las actividades del curso.

Python

Lenguaje de programación de alto nivel, interpretado y de propósito general, utilizado para desarrollo web, análisis de datos, automatización, inteligencia artificial, entre otros.

Versión recomendada: Python 3.10, por su compatibilidad con TensorFlow y el ecosistema de machine learning.

Enlace oficial: Python 3.10

Visual Studio Code

Editor de código fuente gratuito, ligero y altamente extensible, ideal para programar en múltiples lenguajes (JavaScript, Python, Java, C++, entre otros).

Enlace oficial: Visual Studio Code

Pandas, NumPy y Keras

Librerías de Python esenciales para ciencia de datos y machine learning:

  • Pandas: manipulación y análisis de datos (DataFrames, series).
  • NumPy: computación numérica y operaciones con arreglos multidimensionales.
  • Keras: API de alto nivel para redes neuronales y deep learning (basada en TensorFlow).

Requisitos técnicos: Python 3.10 instalado y gestor de paquetes pip para la instalación de las librerías.
