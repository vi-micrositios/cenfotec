Ejercicio: ¿Qué pasa cuando ocurre un error?

Instrucciones: Seleccione un contexto y utilice try / except para controlar un error sencillo relacionado con la lectura de un archivo.

Seleccione un contexto

Cargar una partida

El programa intenta abrir un archivo llamado partida.txt. Si no existe, debe mostrar un mensaje indicando que no se encontró la partida.

Abrir un libro

El programa intenta abrir un archivo con información de un libro. Si el archivo no existe, debe informar al usuario.

Cargar una playlist

El programa intenta leer una playlist almacenada en un archivo. Si el archivo no está disponible, debe mostrar un mensaje adecuado.

Leer datos

El programa intenta abrir un archivo de datos. Si el archivo no existe, debe mostrar un mensaje indicando qué ocurrió.

Controle el error

El programa debe:

  1. Intentar abrir el archivo.
  2. Leer el contenido si el archivo existe.
  3. Mostrar un mensaje si el archivo no existe.
  4. Evitar que el programa termine mostrando un error inesperado.

Realice dos pruebas

Prueba 1: Archivo existente

Cree el archivo y compruebe que el programa puede leerlo.

Prueba 2: Archivo inexistente

Cambie el nombre del archivo o elimínelo y compruebe que el programa maneja correctamente la situación.

Recuerde: Manejar una excepción permite que el programa responda de manera controlada cuando ocurre una situación inesperada.
