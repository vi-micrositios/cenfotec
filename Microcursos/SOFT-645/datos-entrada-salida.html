Ejercicio: Mi primer programa en Python

Instrucciones: Seleccione UNO de los contextos propuestos y desarrolle un programa sencillo en Python que permita resolver la situación planteada. Utilice una sintaxis clara, nombres de variables descriptivos y respete las convenciones básicas de programación.

Seleccionar un contexto

Seleccione UNO de los siguientes contextos y construya un programa básico en Python:

  • Crear una presentación personal que solicite el nombre, edad y pasatiempo favorito.
  • Crear la pantalla inicial de un videojuego que solicite el nombre del jugador y muestre un mensaje de bienvenida.
  • Registrar tres datos numéricos de interés y mostrar información básica sobre ellos.
  • Crear una pequeña interfaz para un sistema de inteligencia artificial que solicite el nombre del usuario y el tipo de predicción que desea realizar.
  • Crear un programa que registre una canción, artista y género musical favoritos y muestre una ficha de la canción.

Aplicar buenas prácticas

El programa debe utilizar nombres de variables descriptivos, indentación correcta, comentarios cuando sean necesarios y una organización clara del código.

Recuerde: En este ejercicio no se busca desarrollar un programa complejo, sino familiarizarse con la sintaxis de Python y las buenas prácticas de escritura de código.
