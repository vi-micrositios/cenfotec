Investigación: APIs y protocolo HTTP

Objetivo: Comprender los conceptos clave de las APIs y del protocolo HTTP antes de construir el back-end con Node.js.

APIs (Interfaces de Programación de Aplicaciones)

Investigue y responda

  1. ¿Qué es una API y cuál es su propósito?
  2. Explique la diferencia entre una API pública y una API privada.
  3. Mencione dos ejemplos reales de APIs públicas e indique qué datos o servicios ofrece cada una.
  4. La API que construirán para el proyecto, ¿será pública o privada? Justifique.

Protocolo HTTP

Investigue y responda

  1. ¿Qué es el protocolo HTTP y para qué se utiliza? ¿Qué diferencia hay entre HTTP y HTTPS?
  2. Describa la estructura básica de una petición HTTP y de una respuesta HTTP.
  3. Explique cada una de las partes de una solicitud: método, URL, encabezados (headers) y cuerpo (body). Dé un ejemplo de cada una.
  4. ¿Qué es un código de estado? Explique qué indican los grupos 2xx, 3xx, 4xx y 5xx, con un ejemplo de cada grupo (por ejemplo, 200, 201, 400, 404, 409 y 500).
  5. ¿Qué es el formato JSON y por qué es el más usado para intercambiar datos entre el front-end y el back-end?

Aplicar los conceptos al proyecto SICEN

Con base en el modelado de colecciones de SICEN que elaboró su grupo, diseñe (sin programar) los endpoints de la API. Recuerde: cada endpoint responde a una necesidad del negocio, no a un "obtener todo".

Requerimientos comunes para todos los grupos

  1. Registrar un centro educativo.
  2. Crear un censo con su fecha de apertura y de cierre.
  3. Asignar centros educativos a un censo.
  4. Consultar los censos abiertos de un centro educativo, a partir de su código institucional.
  5. Registrar las respuestas de un centro educativo a un formulario de un censo.
  6. Consultar el avance de un censo: cuántos centros asignados ya enviaron sus respuestas y cuántos faltan.
