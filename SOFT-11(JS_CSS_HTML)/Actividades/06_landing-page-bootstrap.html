Ejercicio: Diseño de páginas informativas con Bootstrap

Objetivo: Diseñar y desarrollar una o varias páginas informativas utilizando Bootstrap, aplicando el sistema de filas y columnas (Grid) y diferentes componentes del framework.

El ejercicio busca que usted aplique de manera práctica los conceptos de grid, columnas, alineación, espaciado y componentes reutilizables para construir una interfaz informativa coherente, funcional.

Organización de los equipos

El ejercicio se realizará en los grupos del proyecto. Cada equipo deberá seleccionar uno de los tres tipos de páginas informativas disponibles de acuerdo a las necesidades del cliente de SICEN. La cantidad de páginas a desarrollar dependerá de la cantidad de integrantes del equipo.

Cantidad de páginas por equipo

  • 1 integrante: desarrollar 1 página.
  • 2 integrantes: desarrollar 2 páginas.
  • 3 integrantes: desarrollar 3 páginas.

Importante: Si el equipo está conformado por dos integrantes, por ejemplo, deberá desarrollar dos páginas informativas. Las páginas pueden pertenecer al mismo tipo o combinar diferentes tipos de páginas, según la organización definida por el equipo.

Seleccionar el tipo de página

Seleccione uno de los siguientes tipos de páginas informativas. Cada tipo tiene un propósito diferente dentro de un sistema institucional.

Opción 1: Landing page

Una landing page tiene como propósito presentar de manera clara y atractiva un servicio, proyecto, plataforma, iniciativa o funcionalidad. Debe captar la atención del usuario y facilitar que encuentre rápidamente la información o acción principal.

Propósito: comunicar rápidamente qué es el servicio o proyecto y orientar al usuario hacia las acciones principales.
Opción 2: Centro de ayuda / Soporte

El Centro de ayuda tiene como propósito ofrecer recursos que permitan a los usuarios aprender a utilizar un sistema, resolver dudas y encontrar información cuando necesitan asistencia.

Propósito: ayudar al usuario a encontrar respuestas y recursos de soporte sin necesidad de conocer previamente el funcionamiento del sistema.
Opción 3: Noticias / Comunicados

Esta página tiene como propósito presentar información de interés general para los usuarios, como novedades, fechas importantes, cambios y comunicados relacionados con el servicio.

Importante: esta página debe utilizarse para comunicación general. Los comunicados específicos dirigidos a un centro educativo deberían manejarse dentro del sistema mediante el módulo de notificaciones.

Propósito: mantener a los usuarios informados sobre novedades y acontecimientos relevantes del servicio.

Definir la estructura de la página

Antes de comenzar a escribir el código, determine qué secciones tendrá la página y cómo se distribuirán utilizando el sistema de filas y columnas de Bootstrap.

La página debe considerar

  • Una estructura general organizada mediante container.
  • Al menos una estructura basada en row.
  • Uso de diferentes clases col-* para distribuir el contenido.
  • Secciones visualmente diferenciadas.
  • Una jerarquía visual clara entre títulos, contenido y acciones.

Nota: La próxima semana se ajustará esa página para que pueda adaptarse a diferentes tamaños de pantalla.

Utilizar el sistema de Grid de Bootstrap

La página debe construirse utilizando el sistema de grillas de Bootstrap. No se debe resolver toda la distribución utilizando únicamente CSS personalizado.

Requisitos del Grid

  • Utilizar container o container-fluid.
  • Utilizar al menos 3 filas (row).
  • Utilizar columnas de Bootstrap para organizar el contenido.
  • Utilizar al menos una combinación de columnas diferente a col-12.
  • Utilizar clases de espaciado de Bootstrap cuando sean apropiadas, como m-*, p-* o gap-*.
  • Utilizar clases de alineación cuando sean necesarias.
Resultado esperado: una página cuya estructura principal sea reconociblemente construida mediante el sistema de Grid de Bootstrap.

Incorporar componentes de Bootstrap

Además del sistema de Grid, la página debe utilizar diferentes componentes de Bootstrap que sean apropiados para el tipo de contenido seleccionado. No es necesario utilizar todos los componentes disponibles. Seleccione aquellos que aporten valor a la página.

Componentes sugeridos

  • Cards: para presentar servicios, noticias, recursos o categorías.
  • Buttons: para acciones principales y llamadas a la acción.
  • Carousel: para destacar imágenes, noticias o contenidos principales.
  • Accordion: especialmente útil para preguntas frecuentes.
  • Alerts: para información importante o avisos.
  • Badges: para categorías, estados o etiquetas.
  • Navbar: para navegación entre secciones o páginas.
  • List group: para organizar recursos, enlaces o categorías.
  • Modal: para mostrar información adicional cuando sea apropiado.

Importante: los componentes deben seleccionarse de acuerdo con la función de la página. No se trata de colocar componentes únicamente para aumentar su cantidad, sino de utilizarlos cuando ayuden a presentar o organizar mejor la información.

Resultado final esperado: Una o varias páginas informativas desarrolladas con Bootstrap, utilizando correctamente el sistema de grillas mediante filas y columnas y componentes del framework.
