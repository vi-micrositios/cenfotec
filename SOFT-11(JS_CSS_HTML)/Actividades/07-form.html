Ejercicio: Formulario responsivo con Bootstrap

Objetivo: Diseñar y desarrollar un formulario web responsivo utilizando Bootstrap, aplicando el sistema de filas y columnas (Grid), los componentes de formulario del framework y sus clases de validación para ofrecer mensajes claros y significativos al usuario.

Contexto

Seleccionar uno de los tipos de formulario disponibles de acuerdo con las necesidades del cliente de SICEN.

Definir la estructura del formulario

Antes de comenzar a escribir el código, determine qué campos tendrá el formulario, cómo se agruparán y en qué orden aparecerán. Un formulario bien estructurado guía al usuario paso a paso.

El formulario debe considerar

  • Una estructura general organizada mediante container.
  • Una agrupación lógica de campos en secciones (por ejemplo: datos personales, datos de contacto, credenciales).
  • Uso de <fieldset> y <legend> para delimitar grupos cuando corresponda.
  • Etiquetas <label for="…"> asociadas a cada control.
  • Un orden visual y lógico: primero lo simple, luego lo detallado.
  • Jerarquía clara entre títulos de sección, etiquetas, campos y mensajes de ayuda o error.

Nota: La próxima semana se ajustará ese formulario para que pueda adaptarse a diferentes tamaños de pantalla y para validar los datos del lado del cliente.

Utilizar el sistema de Grid de Bootstrap en el formulario

La distribución de los campos dentro del formulario debe resolverse utilizando el sistema de grillas de Bootstrap. No se debe resolver el diseño usando únicamente CSS personalizado.

Requisitos del Grid

  • Utilizar container o container-fluid.
  • Utilizar al menos 3 filas (row) dentro del formulario.
  • Utilizar columnas de Bootstrap para organizar los campos (col-*).
  • Utilizar al menos una combinación diferente a col-12 (por ejemplo col-md-6 o col-lg-4).
  • Utilizar clases de espaciado de Bootstrap cuando sean apropiadas, como mb-3, p-* o g-*.
  • Utilizar clases de alineación cuando sean necesarias (por ejemplo align-items-end para alinear un botón con un campo).
Resultado esperado: un formulario cuya estructura principal sea reconociblemente construida mediante el sistema de Grid de Bootstrap y se adapte a distintos anchos de pantalla.

Incorporar componentes de formulario de Bootstrap

Además del sistema de Grid, el formulario debe utilizar los componentes de formulario que Bootstrap ofrece. No es necesario usar todos; seleccione los que aporten valor al tipo de formulario elegido.

Componentes sugeridos

  • Form controls: form-control, form-control-lg, form-control-sm para campos de texto, correo, contraseña y área de texto.
  • Select: form-select para listas desplegables (país, categoría, tipo de solicitud).
  • Checks & radios: form-check, form-check-input, form-check-label para opciones y aceptación de términos.
  • Switches: form-switch para preferencias activables (por ejemplo, recibir notificaciones).
  • Input group: input-group con input-group-text para prefijos (por ejemplo, @ en un usuario o un ícono de correo).
  • Floating labels: form-floating para mostrar la etiqueta dentro del campo cuando esté vacío y pequeña cuando tenga contenido.
  • Buttons: btn, btn-primary, btn-outline-secondary para acciones principales y secundarias.
  • Alerts: para mostrar mensajes generales de éxito o error tras el envío.
  • Badges: para marcar campos opcionales, nuevos o recomendados.
  • Tooltips / Popovers: para explicar campos que puedan generar dudas.

Importante: los componentes deben seleccionarse de acuerdo con la función del formulario. No se trata de colocar componentes únicamente para aumentar su cantidad, sino de utilizarlos cuando ayuden a capturar mejor los datos o a guiar al usuario.

Asegurar la responsividad del formulario

El formulario debe verse bien y ser usable en móvil, tableta y escritorio. Bootstrap trabaja con un enfoque mobile-first, por lo que las clases base aplican a pantallas pequeñas y los prefijos sm, md, lg, xl ajustan el diseño hacia arriba.

Requisitos de responsividad

  • En móvil, los campos deben apilarse (col-12).
  • En tableta, agrupar en dos columnas (col-md-6).
  • En escritorio, permitir hasta tres columnas cuando aplique (col-lg-4).
  • Utilizar g-3 o gx-* y gy-* para separar columnas y filas sin usar márgenes manuales.
  • Los botones deben ocupar todo el ancho en móvil (w-100 w-md-auto o d-grid d-md-block).
  • Los mensajes de validación deben permanecer visibles sin romper el layout en pantallas pequeñas.
  • Verificar el resultado en al menos tres anchos distintos usando las herramientas de desarrollo del navegador.

Importante: la responsividad no se limita al tamaño de los campos. También incluye el tamaño de las etiquetas, la separación entre bloques, el orden visual de las secciones y la facilidad para completar el formulario en pantallas táctiles.
