Ejercicio: Diseño de una página utilizando Bootstrap

Objetivo: Diseñar una página web utilizando el sistema Grid de Bootstrap, aplicando correctamente contenedores, filas y columnas para reproducir una estructura visual determinada, sin utilizar posicionamiento absoluto.

Estructura que debe construir

La página debe reproducir visualmente la siguiente distribución utilizando el sistema Grid de Bootstrap. Observe la proporción de cada área y utilice las clases de columnas correspondientes.

Configurar Bootstrap

Cree un documento HTML e incorpore Bootstrap mediante CDN. La página debe utilizar las clases de Bootstrap para construir la cuadrícula y distribuir los elementos.

  • Utilizar un container-fluid como contenedor principal.
  • Utilizar row para crear las filas.
  • Utilizar col-12, col-2, col-10 y col-3 según la estructura indicada.
  • Utilizar las clases d-flex, justify-content-evenly y align-items-center para distribuir los tres contenedores interiores.

Construir la distribución

Reproduzca visualmente la distribución indicada respetando las proporciones del sistema de 12 columnas de Bootstrap.

  • La primera fila debe contener un elemento que ocupe las 12 columnas.
  • La segunda fila debe dividirse en una columna de 2 y otra de 10.
  • Dentro de la columna de 10, cree una nueva fila.
  • La fila interior debe contener tres columnas de tamaño 3.
  • Los tres elementos interiores deben distribuirse horizontalmente utilizando Flexbox de Bootstrap.

Comprobar el resultado

  • Verifique que la estructura respete las 12 columnas de Bootstrap.
  • Compruebe que la columna lateral ocupe 2 columnas y el área principal 10.
  • Compruebe que existan exactamente tres contenedores grises.
  • Verifique que los contenedores interiores estén alineados y distribuidos mediante las clases de Bootstrap indicadas.
  • Pruebe la página modificando el ancho de la ventana del navegador.
Resultado esperado: Una página HTML que reproduzca la distribución solicitada utilizando correctamente el sistema Grid y las clases de Flexbox de Bootstrap.
