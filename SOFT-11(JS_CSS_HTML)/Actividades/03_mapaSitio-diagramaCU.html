Ejercicio 3: Diseño de SICEN

Objetivo: A partir de los requerimientos funcionales definidos para SICEN (Sistema de Gestión de Censos Escolares), diseñar la estructura de navegación del sistema mediante un mapa de sitio y representar las principales funcionalidades y actores mediante un diagrama de casos de uso UML.

Diseñar el mapa de sitio de SICEN

Analice los requerimientos funcionales de SICEN y construya un mapa de sitio que represente la organización jerárquica de las principales páginas, módulos y opciones de navegación del sistema.

Instrucciones:

  • Identifique las secciones principales que debe contener SICEN.
  • Organice los módulos y páginas en una estructura jerárquica.
  • Determine qué opciones estarán disponibles para cada tipo de usuario.
  • Represente claramente la relación entre la página principal, los módulos y sus respectivos submódulos.

Ejemplo de estructura:
Inicio → Gestión de centros educativos → Consultar centro → Ver información censal
Inicio → Censo escolar → Registrar información → Actualizar información
Inicio → Reportes → Reportes de estudiantes → Reportes de personal

Resultado esperado: Un mapa de sitio que represente de manera clara, ordenada y jerárquica la estructura de navegación de SICEN.

Diseñar el diagrama de casos de uso de SICEN

A partir de los requerimientos funcionales identificados y del mapa de sitio elaborado en la Parte I, construya un diagrama de casos de uso UML para representar los actores que interactúan con SICEN y las funcionalidades que cada uno puede realizar.

Instrucciones:

  • Identifique los actores que interactúan con SICEN.
  • Identifique los principales casos de uso del sistema.
  • Relacione cada caso de uso con el requerimiento funcional correspondiente.
  • Determine qué casos de uso pueden utilizar relaciones <<include>> o <<extend>>.
  • Delimite claramente el sistema mediante el límite del sistema.
  • Utilice correctamente la notación UML.

Ejemplo de relaciones:
Director → Iniciar sesión Director → Registrar información del censo
Director → Actualizar información censal
Funcionario del censo → Validar información
Administrador → Gestionar usuarios
Usuario consultor → Consultar información
Generar reporte <<include>> Consultar información

Resultado esperado: Un diagrama de casos de uso UML que represente claramente los actores, funcionalidades y relaciones principales de SICEN.
