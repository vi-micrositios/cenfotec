Ejercicio: Investigación sobre el framework frontend Bootstrap

Objetivo: Realizar una investigación sobre el framework frontend Bootstrap, comprendiendo su sistema de grillas, breakpoints, componentes y herramientas de alineación, y relacionando la teoría con ejemplos de código funcionales.

La investigación debe permitir comprender no solamente qué hace cada recurso de Bootstrap, sino también cómo y cuándo utilizarlo en una página web adaptable y accesible.

Orientaciones para la investigación

Consulte fuentes confiables para desarrollar la investigación. Se recomienda utilizar como fuente principal la documentación oficial de Bootstrap y complementar con otras fuentes técnicas de calidad.

Documentación recomendada

Sitio oficial de Bootstrap

La investigación debe incluir las fuentes consultadas y una breve referencia de qué información fue obtenida de cada una.

Investigar el sistema de filas y columnas

Explique cómo funciona el sistema de grid o grilla de Bootstrap y cómo se organiza una interfaz mediante filas y columnas.

Aspectos que debe investigar

  • ¿Qué es el sistema de grid de Bootstrap?
  • ¿Cuál es la función de container, row y col?
  • ¿Cómo se distribuyen las columnas dentro de una fila?
  • ¿Cómo se construyen columnas de diferentes tamaños?
  • ¿Qué ocurre cuando la suma de las columnas supera el espacio disponible?
  • ¿Cómo pueden combinarse varias columnas dentro de una misma fila?

Actividad práctica: Incluya al menos tres ejemplos de código de filas y columnas utilizando configuraciones diferentes. Para cada ejemplo explique qué distribución se espera observar en pantalla.

Resultado esperado: Explicación clara del sistema de grid y ejemplos de código acompañados de una descripción del resultado visual.

Investigar los Media Queries y breakpoints de Bootstrap

Investigue cómo Bootstrap permite construir interfaces responsive, es decir, interfaces capaces de adaptar la distribución de sus elementos a diferentes tamaños de pantalla.

Aspectos que debe investigar

  • ¿Qué función cumplen los breakpoints en Bootstrap?
  • Explique los breakpoints sm, md, lg, xl y xxl.
  • ¿Cómo se adaptan las columnas a diferentes tamaños de pantalla?
  • ¿Qué significa utilizar clases como col-sm-6 o col-lg-4?
  • ¿Cómo puede una misma grilla presentar diferentes distribuciones en dispositivos pequeños y grandes?
  • Explique qué ocurre cuando no se especifica un breakpoint.

Ejemplo obligatorio

Cree una misma grilla que se comporte de una manera en pantallas pequeñas y de otra manera en pantallas grandes. Utilice específicamente clases asociadas con sm y lg.

Documente el resultado utilizando capturas de pantalla o una demostración funcional y explique qué cambia entre ambas resoluciones.

Resultado esperado: Explicación de los breakpoints y demostración funcional de una grilla adaptable.

Investigar los componentes de Bootstrap

Investigue los siguientes componentes de Bootstrap. Para cada componente explique su funcionalidad, principales características, clases utilizadas y casos de uso.

Componentes que debe investigar

  • Navbar: barra de navegación.
  • Buttons: botones e interacción.
  • Cards: presentación estructurada de contenido.
  • Dropdown: menús desplegables.
  • Forms: formularios y controles de entrada.
  • Carousel: presentación de contenido mediante desplazamiento.
  • Tables: presentación estructurada de datos.
  • Tooltips: descripciones emergentes asociadas a elementos.

Requisito práctico: Para cada componente cree como mínimo dos ejemplos funcionales de implementación. Los ejemplos deben ejecutarse correctamente y permitir comprobar visualmente o mediante interacción el funcionamiento del componente.

Navbar

Investigue su estructura, navegación, enlaces, logotipo, comportamiento adaptable y posibilidades de organización.

Buttons

Investigue variantes, tamaños, estados y formas de presentación de los botones.

Cards

Investigue cómo organizar títulos, textos, imágenes, enlaces y botones dentro de una tarjeta.

Dropdown

Investigue la creación de menús desplegables y su comportamiento mediante interacción.

Forms

Investigue campos, etiquetas, controles, agrupación y presentación visual de formularios.

Carousel

Investigue indicadores, controles de navegación y presentación de varios contenidos.

Tables

Investigue clases para tablas, encabezados, filas, bordes y presentación de datos.

Tooltips

Investigue cómo se muestran las descripciones emergentes y qué recursos adicionales requiere su funcionamiento.

Resultado esperado: Documento de investigación acompañado de ejemplos funcionales para cada uno de los componentes estudiados.

Investigar la alineación horizontal y vertical

Investigue las herramientas de alineación proporcionadas por Bootstrap mediante Flexbox.

Aspectos que debe investigar

  • ¿Qué función cumple la clase d-flex?
  • ¿Cómo funciona justify-content?
  • ¿Cómo funciona align-items?
  • ¿Cuál es la diferencia entre alineación horizontal y vertical?
  • ¿Qué otras clases de utilidad pueden utilizarse para controlar la posición y distribución?

Actividad práctica

Cree ejemplos en los que varios elementos estén alineados horizontalmente y verticalmente. Documente las clases utilizadas y explique qué efecto produce cada una.

Resultado esperado: Demostraciones funcionales de diferentes métodos de alineación y explicación del comportamiento obtenido.

Investigar buenas prácticas al utilizar Bootstrap

Analice recomendaciones para utilizar Bootstrap de manera organizada, mantenible, responsive y accesible.

Como mínimo, analice

  • Uso adecuado de las clases y utilidades del framework.
  • Organización consistente del código HTML.
  • Evitar depender innecesariamente de estilos duplicados.
  • Uso adecuado del sistema responsive.
  • Compatibilidad entre estructura, contenido y presentación.
  • Consideraciones de accesibilidad en los componentes.
  • Uso correcto de componentes interactivos.
  • Importancia de consultar la documentación oficial antes de implementar.

Importante: No se limite a enumerar buenas prácticas. Para cada una, explique por qué es importante y presente un ejemplo breve de una implementación adecuada o inadecuada.

Resultado esperado: Conjunto de recomendaciones justificadas mediante ejemplos.

Elaborar la entrega de la investigación

Integre los resultados de la investigación en un documento organizado y acompañado de las evidencias de las pruebas realizadas.

La entrega debe incluir

  • Introducción breve sobre Bootstrap.
  • Explicación del sistema de filas y columnas.
  • Explicación de los breakpoints y comportamiento responsive.
  • Ejemplos de grillas en diferentes configuraciones.
  • Ejemplo comparativo utilizando sm y lg.
  • Investigación de los ocho componentes solicitados.
  • Dos ejemplos funcionales de cada componente.
  • Ejemplos de alineación horizontal y vertical.
  • Buenas prácticas justificadas.
  • Capturas de pantalla o evidencias de los ejemplos ejecutados.
  • Fuentes bibliográficas o enlaces consultados.

Criterio importante: Los ejemplos de código deben ser comprensibles y funcionales. No se considerará suficiente copiar código de una fuente sin explicar qué hace, cómo funciona y qué resultado produce.

Reto integrador

Como parte final de la investigación, construya una pequeña página demostrativa que integre varios de los recursos investigados. La página debe utilizar una grilla responsive, al menos un componente de navegación, botones, tarjetas, un formulario y elementos de alineación. Debe comprobarse su comportamiento en diferentes tamaños de pantalla.

Resultado final esperado: Una investigación técnica y aplicada que demuestre que la persona estudiante comprende el sistema responsive de Bootstrap, su sistema de grillas, sus componentes, sus herramientas de alineación y sus buenas prácticas, y que además puede implementarlos mediante código funcional.
