Ejercicio: Construcción de tarjetas con Bootstrap

Objetivo: Completar la sección de tarjetas de la página SICID utilizando el sistema de filas y columnas de Bootstrap, combinando clases del framework con los estilos CSS proporcionados.

El ejercicio busca que usted aplique de manera práctica los conceptos de grid, columnas, alineación, espaciado y diseño responsive para reproducir una estructura visual a partir de una referencia.

Archivos de trabajo

Para realizar el ejercicio se proporciona una página HTML que ya contiene la estructura general de SICID, Bootstrap, Font Awesome y una hoja de estilos CSS propia.

Archivos proporcionados

  • HTML: archivo ponadis.html
  • CSS: archivo css/ponadis.css
  • Framework: Bootstrap 5
  • Iconos: Font Awesome

Enlaces de referencia

Archivo HTML: ponadis.html

Hoja de estilos: ponadis.css

Identificar la sección que debe completar

Abra el archivo ponadis.html y localice el comentario:

<!-- TODO: TARJETAS -->

Esta es la sección que debe desarrollar. La estructura anterior de la página ya está construida y no debe ser modificada para resolver este ejercicio.

Analizar la referencia visual

Observe la imagen de referencia proporcionada para determinar la estructura general de las tarjetas. No es necesario reproducir exactamente los colores, tamaños o espacios. Lo importante es conservar la organización general de los elementos.

Importante: La imagen funciona como una referencia de estructura y composición. La apariencia final puede presentar diferencias de color, tamaño, tipografía o espaciado siempre que se conserve la organización solicitada.

Construir la estructura utilizando Bootstrap

Construya las cinco tarjetas utilizando el sistema de filas y columnas de Bootstrap. La solución debe partir de una estructura basada en row y col.

Requisitos de estructura

  • Crear las 5 tarjetas.
  • Utilizar al menos una estructura basada en row.
  • Utilizar columnas de Bootstrap para distribuir las tarjetas.
  • Conseguir una distribución visual similar a la referencia.
  • Utilizar clases de Bootstrap para alineación y espaciado cuando resulte apropiado.
Resultado esperado: Cinco tarjetas distribuidas mediante el sistema de grid de Bootstrap.

Incorporar el contenido de las tarjetas

Cada tarjeta debe contener un número y uno de los textos correspondientes a las opciones disponibles en la pantalla principal de SICID.

Contenido requerido

  1. Crear componentes de la Política Nacional en Discapacidad
  2. Ver las Políticas Nacionales en Discapacidad existentes
  3. Editar los componentes de la versión más reciente de PONADIS
  4. Aprobar publicación de la PONADIS
  5. Cambiar a la visualización/edición de otra sección

Recomendación: Utilice elementos HTML semánticos siempre que sea posible. Si una tarjeta representa una opción seleccionable, considere cómo debería estructurarse para que también sea comprensible mediante teclado y tecnologías de asistencia.

Construir las tarjetas utilizando diferentes técnicas

En esta parte deberá construir las cinco tarjetas solicitadas utilizando dos formas diferentes de implementación: una tarjeta desarrollada completamente de forma manual con HTML y CSS, y otra utilizando el componente Card de Bootstrap.

Documentación de referencia

Para la segunda tarjeta consulte la documentación oficial del componente Card de Bootstrap:
Documentación oficial de Bootstrap - Cards

Tarjeta 1: Construcción manual con HTML y CSS

La primera tarjeta debe construirse completamente de forma manual. No utilice el componente Card de Bootstrap.

Requisitos:

  • Crear la estructura utilizando HTML.
  • Crear mediante CSS los estilos necesarios para obtener la apariencia de la tarjeta.
  • Crear manualmente el círculo que contiene el número.
  • Crear manualmente el espacio, bordes, esquinas redondeadas, alineación y demás características visuales.
  • No utilizar el componente Card de Bootstrap.
  • No copiar directamente una tarjeta prediseñada de Bootstrap para esta primera tarjeta.

Propósito

Demostrar que comprende cómo construir un componente visual desde cero utilizando únicamente la estructura HTML y las propiedades CSS necesarias.

Tarjeta 2: Utilizando el componente Card de Bootstrap

La segunda tarjeta debe construirse utilizando el componente Card de Bootstrap.

Requisitos:

  • Utilizar la estructura del componente Card proporcionada por Bootstrap.
  • Utilizar las clases propias del componente cuando corresponda.
  • Agregar las clases CSS necesarias para modificar su apariencia.
  • La tarjeta debe adaptarse visualmente a la referencia proporcionada en la Parte II.
  • El resultado final no debe conservar simplemente la apariencia predeterminada de Bootstrap.
  • Debe modificar aspectos como tamaño, bordes, esquinas, colores, alineación, número y espaciado según sea necesario.

Personalización obligatoria

Utilizar Bootstrap no significa aceptar la apariencia predeterminada del componente. Debe crear los estilos adicionales necesarios para que esta segunda tarjeta tenga una apariencia visual equivalente a la referencia.

Resultado esperado: Una tarjeta construida utilizando el componente Card de Bootstrap, pero personalizada mediante CSS para aproximarse visualmente a la tarjeta de referencia.
Tarjetas 3, 4 y 5 — Selección de la técnica

Para las tres tarjetas restantes puede seleccionar libremente cualquiera de las dos técnicas anteriores.

Puede elegir entre:

  • Construcción manual mediante HTML + CSS.
  • Utilización del componente Card de Bootstrap + CSS personalizado.

Importante: Aunque pueda escoger la técnica, las tarjetas 3, 4 y 5 deben mantener la misma estructura visual general y ser coherentes con las tarjetas anteriores.

Resultado final esperado: Cinco tarjetas funcionales y visualmente coherentes con la referencia. La primera debe estar construida manualmente con HTML y CSS; la segunda debe utilizar el componente Card de Bootstrap y ser personalizada mediante CSS; y las tres restantes pueden utilizar cualquiera de las dos técnicas.

Investigar los breakpoints de Bootstrap

Antes de adaptar las tarjetas a diferentes tamaños de pantalla, investigue qué son los breakpoints y cómo funcionan dentro de Bootstrap. El objetivo de esta actividad es comprender la función de los breakpoints y reconocer las diferentes categorías disponibles en Bootstrap. No es necesario modificar todavía las tarjetas para hacerlas responsive.

Fuente recomendada

Consulte principalmente la documentación oficial de Bootstrap sobre el sistema responsive y sus breakpoints:
Documentación oficial de Bootstrap - Breakpoints

Puede complementar la investigación con otras fuentes técnicas confiables. Incluya las fuentes consultadas en la entrega.

Aspectos que debe investigar

  • ¿Qué es un breakpoint en diseño responsive?
  • ¿Para qué sirven los breakpoints en Bootstrap?
  • ¿Qué relación existe entre los breakpoints y el tamaño de la pantalla?
  • ¿Cuáles son los breakpoints disponibles en Bootstrap 5?
  • ¿Qué significan las abreviaturas sm, md, lg, xl y xxl?
  • ¿Qué significa el comportamiento extra small o tamaño base cuando no se especifica un breakpoint?
  • ¿Qué diferencia existe entre utilizar una clase como col-12 y una clase como col-md-6?
  • ¿Qué ocurre cuando se combinan diferentes breakpoints en una misma estructura?
  • ¿Por qué los breakpoints permiten construir interfaces que se adaptan a diferentes tamaños de pantalla?

Próxima etapa

En la siguiente parte se trabajará la aplicación práctica de estos conceptos. En la clase se explicará cómo utilizar los breakpoints y otras herramientas de Bootstrap para adaptar la distribución de las tarjetas a diferentes tamaños de pantalla.

Resultado final esperado: Una página SICID que incluya cinco tarjetas correctamente estructuradas mediante HTML y Bootstrap, con una distribución semejante a la referencia visual, contenido correcto, integración con los estilos proporcionados y comportamiento adecuado en diferentes tamaños de pantalla.
