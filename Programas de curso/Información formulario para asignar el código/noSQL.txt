Microcurso 1: Fundamentos de bases de datos NoSQL
Ingrese el nombre del curso:
Fundamentos de bases de datos NoSQL

Descripción del curso
Este curso  introduce los fundamentos de las bases de datos NoSQL y su rol frente al modelo relacional. Se estudian las limitaciones del modelo relacional en escenarios de flexibilidad, volumen, escalabilidad y datos semiestructurados o no estructurados, así como el surgimiento de NoSQL y su relación con aplicaciones distribuidas y datos modernos. El estudiante comprende el concepto de NoSQL, la flexibilidad de esquema y los tipos de datos, y compara SQL frente a NoSQL en modelado, consultas, consistencia, escalabilidad y casos de uso. Se revisan casos típicos como catálogos, perfiles, sesiones, logs, eventos, contenido, IoT y aplicaciones web o móviles. El curso se alinea con SFIA 8 en Diseño de datos (DTAN) nivel 2, con apoyo en Desarrollo de software (PROG) nivel 2 y Métodos y herramientas (METL) nivel 3. Como resultado, el estudiante reconoce cuándo una base NoSQL puede ser adecuada y distingue criterios iniciales de selección según tipo de dato, patrón de acceso, consistencia y escalabilidad. No requiere experiencia previa en NoSQL, aunque se recomiendan nociones generales de bases relacionales y manejo básico de JSON, APIs, Git y programación en Python.

Perfil de ingreso
Requisito general del Path: Python Foundations: Programación Aplicada desde Cero o suficiencia equivalente.

Curso  ninguno (primer curso ).

Palabras clave
NoSQL, modelo relacional, flexibilidad de esquema, datos semiestructurados, escalabilidad, consistencia, casos de uso, SQL vs. NoSQL, datos modernos, aplicaciones distribuidas.

Contenidos principales
Evolución de las bases de datos: limitaciones del modelo relacional, surgimiento de NoSQL, datos modernos, aplicaciones distribuidas.

Fundamentos NoSQL: concepto de NoSQL, flexibilidad de esquema, datos estructurados, semiestructurados y no estructurados.

SQL vs. NoSQL: diferencias de modelado, consulta, consistencia, escalabilidad y casos de uso.

Casos de uso NoSQL: catálogos, perfiles, sesiones, logs, eventos, contenido, IoT, aplicaciones web y móviles.

Microcurso 2: Modelos de datos NoSQL y selección tecnológica
Ingrese el nombre del curso:
Modelos de datos NoSQL y selección tecnológica

Descripción del curso
Este curso  aborda la selección de modelos de persistencia NoSQL y la elección tecnológica según las necesidades de una solución. Se comparan los modelos documental, key-value, column-family y grafos, considerando estructura de datos, patrones de consulta, escalabilidad, consistencia, costo y mantenibilidad. El estudiante analiza casos empresariales o técnicos, identifica trade-offs y elabora una matriz de selección tecnológica que justifica la elección del modelo NoSQL. Se profundiza en documentos, colecciones, JSON, estructuras anidadas, claves y valores, acceso directo, caché, sesiones, datos temporales, wide-column y relaciones altamente conectadas. El curso se alinea con SFIA 8 en Diseño de datos (DTAN) nivel 3, con apoyo en Integración de sistemas (SINT) nivel 3 y Métodos y herramientas (METL) nivel 3. El estudiante produce modelos lógicos y contribuye a seleccionar componentes y técnicas de diseño. Como resultado, puede justificar técnicamente una elección NoSQL y reconocer cuándo cada modelo resulta más conveniente. Se requiere haber aprobado Fundamentos de bases de datos NoSQL y comprensión de diferencias SQL/NoSQL.
